### A2. 推演暴露矛盾

**Claude**：（用 1000 金推演）T1 末 120 金 → 攒到 1000 需要 ~3 分钟 → 破坏"2-4 分钟是 T2 阶段"的设计。

**核心矛盾**：T2 升级 + 靶场 + 弓兵 = ~1:30，T2 阶段（2-4 分钟）实际上几乎没有 T2 单位作战。

## 五、D 模块：兵种全局升级细节

**用户回答**：

- 步兵特色：**每 10s 触发一次回血吧**
- 农场城堡：**仅 1 条线**

### 第二轮（数值细化 + 重大设计新增）

**Claude**：（问 4 个 Q）
- 升级费用倍率
- 单位升级加成类型
- 农场城堡科技具体效果
- 特色升级数值 + 费用

**用户回答**（含重大设计）：
- 费用倍率：**通用 1.5x**
- 加成类型：**百分比加成**
- 农场城堡（关键新设计）：
  > 农场就产量增加把，这样他后期收益更高；城堡就升级箭塔的一些数值，还有整体建筑物血量这两样吧。可能还可以升级一个兵营类建造速度。这些都是单次升级的吧。不像前面攻防是升3次这种。
- 特色升级（关键新设计）：
  > 大概这样的，步兵这个升级是中级一点的感觉，每5秒回复5%这样的吧。弓兵这个也是，中级，减速2秒20%吧先。然后所谓初级中级高级，就对应1本可升级、二本可升级、三本升级这种。

**新设计浮现**：
- 农场/城堡科技是**单次升级**（不是 3 级线）
- 城堡科技是**3 个独立单次升级**（箭塔 / 血量 / 兵营造速）
- 单位特色升级分**T1/T2/T3 三级递增**（每本解锁 1 级）

### 第三轮（最终数值）

- 百分比加成数值
- 农场科技具体效果
- 城堡 3 项数值
- 特色升级分级费用

**用户回答**：

### 第二轮（2026-08-06，UI 详细枚举）

**用户开场**（重大重构）：
> 建筑**光环不要**。然后这样，因为 UI 这里改版，我认为是非常巨大的。我们需要详细聊一下具体左边显示啥，右边显示啥这种内容。左侧因为是和现在一样，就是几个 tab，底下是造兵、造建筑，还有哪个占领据点的特殊建筑，还有啥，对吧，能不能全枚举出来；然后，右侧显示详细信息，对应比如选择左侧 UI 的建筑、单位时候显示啥，点击地图里的单位、建筑，多单位等等的时候，有哪些情况，分别显示啥；比如又框选了单位，又点了建筑的时候该怎么样？这里感觉展开要聊很多东西。

**Claude**：（列左侧 QW 内容清单 + 右侧详情面板 L1-L9 触发情况清单）

#### UI Q1 第一组（左侧 QW 分类）
- QW 分类方式：**不分类大网格**（所有可造项一屏展示，无 tab 切换）
- 图标排列：**不分类**（混合排列）
- 多选异类（步兵+弓兵）：**两类汇总**
- 框选单位 + 点建筑：**切建筑详情 + 保留选中**

#### UI Q2 第二组（多选 & 未解锁）
- 多选同建筑（2 个兵营）：**汇总信息**
- 混选建筑 + 单位：**仅主单位**
- 未解锁项展示：**灰色锁**（看得到但不可点）
- 排列顺序：**时代顺序**（T1→T2→T3）

#### UI Q3 第三组（升级 & 视觉细节）
- 升级按钮视觉：**名称 + 等级 + 费用**
- 在造兵进度展示：**主进度显示**
- 点升级反馈：**即时生效**
- 选中高亮：**维持现状光圈**（用户原话："这个现在也有，就维持现在的光圈这样的把"）

**Claude 观察**：08-06 这轮把 UI 改版的左右两侧细节都聊透了。最大的变化是：
1. **取消预览 tab** → 所有时代内容统一用灰色锁展示
2. **L6-L9 多选场景** → 4 种汇总/切换策略清晰
3. **建筑光环全删**（关联 C 模块的靶场光环）

F 模块最终拍板见 T2 文档 2.3.6 节（含 L1-L9 触发情况表）。

## 十一、关键决策依据（ Why ）

### 为什么 T2 升级是 500 金不是 1000 金？

A3 推演：玩家从 T1 末 120 金攒到 1000 金需要 ~3 分钟，破坏"2-4 分钟是 T2 阶段"的设计。500 金让玩家 3:00 左右能升。

### 为什么 T2 升级反还 300 金？

C 模块推演：T2 升级 + 靶场（250）+ 弓兵（100）= 850 金，T2 阶段收入约 480 金。缺口 ~370 金。反还 300 金让玩家升完能立刻启动靶场+弓兵。

### 为什么双兵营主流？

用户设计意图：T1 阶段鼓励玩家建 2 个兵营（前期便宜后期贵的递增式造价）。双兵营并行造兵，配合 15s/兵的快速产能，T1 末能有 6 兵（vs 单兵营 4 兵）。

### 为什么事件驱动而非时间驱动？

用户原话："我们主要就是定义这个T2，就是1本升2本的情况吧。不要按照时间来话分了"

意图：玩家自由选择升级时机（早升/晚升），不强制定时间窗口。T2 阶段长度可变，战略路径多样化。

### 为什么可取消全退？

用户选了"可取消全退"，意图是给玩家灵活度——骚扰压力大时可以取消升级、用钱补兵防守、再升。10 分钟 PVE 节奏下，exploit 风险（反复试错）可接受。

### 为什么 3 层科技树而不是简单的"3 级全局升级"？

用户原话："一组通用升级，所有单位增加的；每个单位一组升级，血量和攻击；然后每个单位有一点特色升级"

意图：
- 通用升级 = 全局加成（玩家想要所有单位都强）
- 单位基础升级 = 单位独立加成（玩家想特化某个单位）
- 单位特色升级 = 独特玩法（每个单位有一个独特技能，增加辨识度）

### 为什么步兵特色是"每 10s 回血"？

用户原话："每10秒触发一次回血吧"

意图：步兵作为抗线单位，需要续航能力。回血让步兵在长时间作战中更耐用。

### 为什么特色升级分 T1/T2/T3 三级递增？

用户原话（D 模块第二轮）："所谓初级中级高级，就对应1本可升级、二本可升级、三本升级这种"

意图：让玩家在每个本数都有"特色升级"作为本数升级的奖励。T1 玩家可以升初级（500 金），T2 解锁中级（700 金），T3 解锁高级（1000 金）。这样特色升级跟时代升级形成节奏感。

### 为什么农场科技是单次升级而城堡是 3 个独立单次？

用户原话："农场就产量增加把，这样他后期收益更高；城堡就升级箭塔的一些数值，还有整体建筑物血量这两样吧。可能还可以升级一个兵营类建造速度。这些都是单次升级的吧。"

意图：
- 农场科技只升 1 次：因为农场只有 1 个核心属性（产量），不需要多条线
- 城堡 3 项：城堡是综合建筑（防御+经济+建造），3 项分别对应这 3 个维度
- 都是单次升级：避免每项都升 3 级 = 9 个升级节点，玩家升不过来

### 为什么通用升级 1.5x 而不是 2x？

通用升级影响所有单位（步兵+弓兵+未来 T3 单位），价值远高于单单位升级。1.5x 让通用升级"贵但值"，2x 会让玩家完全不想升（太贵），1.2x 会让玩家只升通用（单单位升级没人升）。1.5x 是 sweet spot。

### 为什么 08-06 取消"预览 tab"改成"统一灰色锁"？

用户在 F 模块 08-06 二轮中决定未解锁项一律用灰色锁展示。这等于作废了 G 模块第一轮的"预览 tab"。

意图：
- **少切换**：预览 tab 要点击切换，灰色锁一屏全看到，玩家无需操作
- **路径感强**：所有时代内容（T1/T2/T3）一起摆出来，玩家天然看到"解锁路径"
- **极简哲学延续**：与整体"低调"设计哲学一致，少一个 tab 切换 UI

### 为什么 08-06 删除建筑光环（靶场射程光环）？

用户原话："建筑光环不要"。

意图：简化建筑功能定义。光环会引入"光环范围多大 / 是否叠加 / 多建筑重叠怎么算"等隐藏复杂度。T2 阶段靶场只保留"产弓兵"的核心职能，不加衍生机制。

### 为什么 QW 不分类大网格而不是 tab 分类？

用户在 08-06 二轮选择"不分类大网格"。

意图：
- **一屏全看到**：玩家无需切 tab 就能扫到所有可造项
- **混合排列符合时代顺序**：T1 项 + T2 项 + T3 项（灰色锁）按时代递增排列，分类本身已隐含时代信息
- **配合灰色锁路径感**：不分类让玩家一眼看到从 T1 到 T3 的全解锁路径

### 为什么 L8 混选建筑+单位时"仅主单位"？

用户在 08-06 二轮选择"仅主单位"（最新选中优先）。

意图：避免详情面板信息过载。混选时玩家通常主要关注单位（建筑是被动设施），主单位详情更有用。建筑被忽略时，玩家点回地图即可切到建筑详情（L9 保留切换路径）。

### 为什么 L9 框选单位+点建筑"切建筑详情+保留选中"？

用户在 08-06 二轮选择"切建筑详情 + 保留选中"。

意图：
- 保留"快速侦察"操作：玩家经常框选部队然后点敌方/自家建筑看一眼详情，操作完想回来继续指挥部队
- 部队选中状态保留 → 玩家点回地图任意空地就能继续指挥部队（避免重复框选）
