## 七、T1 经济数值方案（2026-07-28 已对齐）

### 7.1 核心机制（替代 CD 的引导方案）

**问题**：用 CD 限制建造行为本身反直觉（PVZ 卡的是植物种类 CD 不是建造栏 CD），用户否决。

**方案**：递增加价 + 完成反还。机制字段化，可灵活调整/删除。

- `cost_increment`：同种建筑每多造一个，造价 += 该值。0 = 关闭递增
- `completion_refund`：建筑完成时反还的金币。0 = 关闭反还
- `completion_refund_unit`：建筑完成时反还的单位 id（兵营用，比如 "soldier"）。null = 不反还单位

### 7.2 数值参数

| 项目 | 数值 | 备注 |
|---|---|---|
| 开局金币（默认难度）| **400** | 难度低时可上调 |
| 主基地产金 | **50 / 10s** | 2 个农场等价 |
| 农场基础造价 | **100** | 第 1 个 |
| 农场递增幅度 | **150** | 第 2/3/4/5 个分别是 250/400/550/700 |
| 农场产金 | **20 / 10s** | |
| 农场反还 | **0**（字段保留）| 当前默认关；难度低时可开 30 |
| 农场建造时间 | **20s** | 上限，不再增加 |
| 兵营造价 | **300** | 不递增 |
| 兵营反还 | **2 兵**（约 100 金价值）| |
| 兵营建造时间 | 5s | |
| 兵营产能 | **25s / 兵** | |
| 步兵造价 | **50** | 25 太便宜，运营感弱 |
| 农场上限 | 5（全局硬上限）| |

### 7.3 三种流程推演（T1 末 = 2:00）

#### 流程 A：贪农场（不造兵营）

```
0:00 400 → 造农场1(-100) → 300
0:20 农场1完成 +主基地2跳+100 → 400 → 造农场2(-250) → 150
0:40 农场2完成 +20+50 → 290
0:50 +40+50 → 380
1:00 +40+50 → 470 → 造农场3(-400) → 70
1:20 农场3完成 +60+50 → 270
1:40 +60+50 → 490
1:50 +60+50 → 600 → 造农场4(-550) → 50
2:00 ★ 3 农场完成 + 农场4 在建 + 160 金
```

#### 流程 B：稳一手（造兵营）

```
0:00 造农场1 → 0:20 完成
0:20 造农场2(-250) → 0:40 完成
0:50 → 330 → 造兵营(-300) → 30
0:55 兵营完成 反2兵
1:00 → 70 → 兵营造兵1(-50)
1:25 出兵1
1:30 → 200 → 兵营造兵2(-50)
1:50 → 410 → 造农场3(-400) → 10
2:00 ★ 2 农场完成 + 农场3 在建 + 兵营 + 4 兵（含反2）+ 120 金
```

#### 流程 C：新手延迟（每个操作慢 5-10s）

```
贪：3 农场完成 + 农场4 刚造 + 0 金
稳：2 农场完成 + 1 兵营 + 3 兵（含反2）+ ~200 金
```

### 7.4 对比表

| 流程 | 农场完成 | 在建 | 兵营 | 兵 | 余钱 | 第一波骚扰（3-6 敌兵）|
|---|---|---|---|---|---|---|
| A 贪 | 3 | 1 | 0 | 0 | 160 | ❌ 必爆 |
| B 稳 | 2 | 1 | 1 | 4 | 120 | ✅ 轻松防 |
| C 新手贪 | 3 | 1 | 0 | 0 | 0 | ❌ 必爆 |
| C 新手稳 | 2 | 0 | 1 | 3 | ~200 | ⚠️ 勉强防 |

### 7.5 关键设计意图

1. **递增 150 的心理门槛**：第 4 个农场 550 金让玩家算"550 vs 攒 T2(1000) 一半了"，自然停手 → 实现 PVZ 式"算账分流"
2. **反还关闭**：反还会推高玩家余额破坏节奏；字段保留方便以后开（难度调节）
3. **所有数值整数**：100/250/400/550/700/50/20，无 37 这类奇怪数字
4. **贪流程必爆**：第一波骚扰（3-6 敌兵）会惩罚纯贪农场玩家，引导下次造兵营
5. **三个清晰的决策点**：0:30 / 1:00 / 1:30
