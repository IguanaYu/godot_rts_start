### 第 3 章 视觉基础（已过专业审查 + 修订定稿）

审查结论（2026-08-15，来源见调研报告）：字号数值属实但出处错；**字体是事实错误**（Godot 4 运行时默认 = Open Sans SemiBold 无中文字形，中文回退系统字体跨平台不一致）；76×76 属实但过时；间距 4 档不够；功能色直连美术色板是反模式。

| # | 决策 | 内容 |
|---|---|---|
| 3-1 | 字号四档 22/16/14/12（33/24/21/18 物理），行高 **28/24/20/20**（12px 档中文行高 16→20）；"4pt 基线"说法改为「4px 行高节奏，参照 Material M2 4dp baseline grid」；micro 12px 档限非任务关键信息（关键信息最低 14px）；12px@720 逻辑 = 18px@1080 恰好压线 XAG PC 最低值零余量，记知悉项 | 修订后定稿 |
| 3-2 | 字体 = **内嵌思源黑体（= Noto Sans CJK 同字型，OFL 免费商用）**，≤3 字重（自带 7 真字重选 3），配 theme default font 禁用系统回退；资源数字 Label 统一挂 `tnum`（FontVariation opentype_features），数字抖动时 fallback Noto Sans Mono | 事实修正后定稿；实施进 gap |
| 3-3 | 图标：**新图标源图一律 128×128**（显示 72×72，1.78 倍超采样），现有 76 系列不动逐步替换；透明底、禁自带容器（容器/边框由 UI 层绘制，同 SC2 分层） | 修订后定稿 |
| 3-4 | 间距 token **8 档：4/8/12/16/24/32/48/64**（前四密排、后四布局分区），全部 4 的倍数 8 优先 | 扩档定稿 |
| 3-5 | 功能色 = **三层 token**：A.3 美术色板存 primitive → UI 侧 semantic token（error/success/warning/info，**深底专用值**）→ 组件 token；禁止 UI 直接引用美术色值；删"向高明度调整"（纯深底直接选色）；对比度验收 XAG 102 = WCAG 4.5:1 正文 / 3:1 图标与大字 | 审查修正后定稿 |
| 3-6 | 禁用态统一值 | **待拍**（留第 4 章五态一起拍） |

### 第 4 章 交互规范（已拍板）

| # | 决策 | 内容 |
|---|---|---|
| 4-1 | **禁用态双轨制**：真禁用（满级 MAX/单次已购/队列满）= 压暗 40% 不可点无反馈；假禁用（缺钱/时代锁）= 压暗可点，点击触发报错飘字（SC2 式「点它问原因」）。正式化现有散落行为 | 拍板 2026-08-15 |
| 4-2 | **五态数值**：enabled 基准 / hover scale 1.12+变亮 12% 0.1s / pressed scale 0.90+变暗 20% 0.1s / disabled 真=0.4 / 选中 tab 描边或角标 0.1s 过渡。降级规则：状态反馈用明暗缩放透明度表达不换色相，色相只留语义色 | 现值基本达标，0.12→0.1 统一 |
| 4-3 | **Tooltip 统一 300ms**（收编 600/800 两套）；消失延迟 200ms 可移入不消失；100ms 淡入；结构 SC2 四段式 名称→消耗→热键→描述；锚定按钮上方不遮挡本体；热键操作有效性不许依赖 tooltip 讲清 | 拍板 300ms |
| 4-4 | **报错三通道**：文字（飘字文案公式「缺什么+需要多少」）✅ 已达标 + 音效（进 C.2 需求清单）+ 视觉强化（消耗数字闪红 200ms，点击不足按钮时） | 拍板 |
| 4-5 | 无效放置：保留绿/红 ghost，补「显示一行原因」；不新建 toast 系统（波次预警已有常驻倒计时+marker+小地图红点），未来若做普通 3s/重要 4s/上限 3 条 | |
| 4-6 | **音效需求清单现在写给 C.2**：报错短音、波次预警音、点击音等场景→类型映射 | 拍板写清单 |
| 4-7 | 微文案：错误文案公式 [缺什么]+[需要多少]+(可选)[去哪弄]；数字用阿拉伯不写汉字；>999 显示 1.2k；全部走 translations.csv 禁硬编码中文；术语唯一（据点不混前哨） | |

### 第 5 章 动效规范（已拍板）

| # | 决策 | 内容 |
|---|---|---|
| 5-1 | 三档 token：motion-fast 100ms（按钮态/tooltip 淡入/闪红）/ motion-medium 250ms（面板开关）/ motion-slow 400ms（全屏遮罩/结算淡入）；硬上限 500ms | button_factory 0.12→0.1 统一 |
| 5-2 | 缓动：进入 ease-out / 退出 ease-in / 屏内移动 ease-in-out；现有飘字 BACK/OUT、按钮 QUAD/OUT 追认 |
| 5-3 | 高频操作零等待白名单：建造连点/tab 切换/框选/编队/小地图点击/镜头跳转 ≤50ms 或无动画（RTS 特权，M3 250ms 不得照搬） |
| 5-4 | 事件动效：时代解锁闪 0.5→0.4s 压进 token；飘字/血条属**信息载体类豁免 500ms 封顶**（判定口诀：反馈类受 token 管，信息载体类时长按可读性定） | 拍板豁免版 |
| 5-5 | 飘字系统未来重新设计（用户评"确实不是特别合适"），豁免条款随重新设计再审 | 灵感记入 |
