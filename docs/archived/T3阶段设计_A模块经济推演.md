## 二、🔥 与 T3 文档不一致的 3 处关键修正

### 修正 1：T2/T3 升级完成**不反还金币**

文档说"T2 反还 300 / T3 反还 500"。**代码实际**：
- 取消升级 → 全额退款
- 升级完成 → **不反还**

意味着升 T2 净支出 500 金，升 T3 净支出 1000 金。文档"启动链"（反还 500 立刻建长矛兵营）失效。

### 修正 2：长矛兵/僧侣 T1 就解锁（代码层），不是 T3 新单位

`_unlock_age_items(age)` 只处理 `age >= 2` 解锁 `ARCHERY_RANGE + ARCHER`。T1 默认就有长矛兵、僧侣、各种变体单位。

⚠️ **当前测试关卡限制**：通过 `map_config.available_items` 配置，测试关卡目前只有**步兵**（T1）和**弓兵**（T2 解锁），长矛兵和僧侣虽然在代码层是 T1 单位但**当前关卡未开放**，后续会补充。

文档说"C1 长矛兵是 T3 关键新单位"不成立。**T3 解锁什么要重新设计**（"每个单位一种特别厉害的升级"方向，留到 C 模块聊）。

### 修正 3：T2 实际只解锁靶场+弓兵

不是文档暗示的"T2 解锁一大片"：
- T1 = 步兵 + 长矛 + 僧侣（近战 + 反骑 + 治疗）
- T2 = 加弓兵（远程 DPS）
- T3 = 待定（高级升级线）

## 五、🔥 关键发现

1. **10 分钟兵力是 20-50 而非文档原稿的 10-18** —— 文档数值严重低估
2. **金币是真瓶颈，不是产能** —— 双兵营步兵产能 6s/个理论可造 180 个，但金币只够 30-50
3. **T2/T3 升级完成不反还** —— 文档"启动链"假设（反还 500 立刻建长矛兵营）不成立
4. **塔被严重低估** —— 150 金 / DPS 8 / HP 150，DPS 性价比比步兵高（步兵 50 金 DMG 6-8）。需要明确"塔不能进攻据点"作为平衡
5. **T3 已有代码框架** —— `AGE_UPGRADE_COST[3]=1000 / TIME[3]=30s` 已存在，detail_panel.gd 里 T3 升级按钮已工作，实际游戏里能升 T3
6. **T3 解锁内容空白** —— `_unlock_age_items` 没写 age>=3 分支。升 T3 目前只花了 1000 金，啥都没解锁。这是 C 模块要解决的核心

## 七、A 模块决策结果（2026-08-11 拍板）

### Q1. T2/T3 升级反还机制 → **维持现状**

代码不动：取消全额退款 / 完成不反还。改文档去掉"反还 300/500"假设。
- 升 T2 净支出 500 金，升 T3 净支出 1000 金
- 玩家需在升 T3 前预留 1500 金（1000 升级 + 500 启动资金）
- T2 详细稿 B3 / K2 交叉点 2 / K3 数值锚点表里"反还 300/500"全部失效，需修正

### Q2. 主流战略路径 → **4 条核心**

| 主流路径 | 终态画像 | 风格 |
|---|---|---|
| **T2 远近搭配** | 30 兵（步+弓混合）/ T2 升级 | 标准打法 |
| **T3 远近+治疗强化** | 20 兵 / T3 高级升级 | 质量碾压 |
| **纯近战 T2/T3** | 40-50 / 30 近战 / 暴兵流 | 暴兵+质量 |
| **纯弓兵 T2/T3** | 28 弓兵 / 风筝拉扯 | 操作向 |

- **不升本** + **屯兵一波** 算边缘玩法，不强求平衡
- **平衡工作分层**：本阶段只做"经济和整体战力"粗平衡，具体数值小平衡等内容全部确定后再做

### Q3. 塔的定位 → **递增造价 + 单塔强化**

用户原话："塔应该是比较适合过度的前期建筑，能够强化防守，但不能进攻据点。新手玩家只要前期放塔，就能很轻松守住敌人"

| 调整项 | 方向 | 具体数值（待后续校准）|
|---|---|---|
| 递增机制 | 加 cost_increment（类似农场）| 每多一座 +50~100 金 |
| 基础造价 | 微调上调 | 150 → 180~220 |
| 攻击范围 | **明显加大** | 150 → 200~250 |
| 整体属性 | 略升 | HP / DMG / 攻速小幅强化 |

设计目标：前 1-2 座塔性价比明显（新手能守住），3+ 座性价比骤降（防塔海）。
"亏经济这些以后再说" —— 不在本阶段细调数值。

### Q4. A2 升 T3 推荐时机 → **不设推荐**

- 玩家自主选择升 T3 时机
- 未来可能做"教程系统/小助手"提醒新手升本，但属于后续扩展
- T3 详细稿 A2 模块"6:30 推荐"作废，仅保留"事件驱动 + 玩家自选"方法论
