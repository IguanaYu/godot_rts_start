## 六、Bug 记录模板

**所有发现的 bug 都记录在此节**。验证完按严重程度统一修复（D3 决策）。

### Bug 模板

```
### BUG-001 [严重程度] 简短标题
- **现象**：描述观察到的问题
- **复现步骤**：
  1. 步骤 1
  2. 步骤 2
- **预期**：应该发生什么
- **实际**：实际发生了什么
- **涉及文件**：路径:行号（如已知）
- **状态**：待修复 / 修复中 / 已修复 / 已验证
```

### 严重程度定义

| 等级 | 描述 | 示例 |
|---|---|---|
| **BLOCKING** | 阻塞验证，无法继续 | 游戏崩溃 / T1 测试按钮无法点击 |
| **MAJOR** | 核心功能异常但不崩溃 | 农场不产金 / 兵营不出兵 |
| **MINOR** | 功能异常但有 workaround | 偶尔卡顿 / 数值偏差超容差 |
| **COSMETIC** | 视觉问题，不影响玩法 | 图标错位 / 文字截断 |

### T1 阶段通过条件

- [ ] **没有 BLOCKING bug**

## 十、验证流程总结

```
1. PR-1 验证（现在可做）
   └─ 用第二节清单
   └─ Bug 记录到第六节

2. PR-2 验证（现在可做）
   └─ 用第三节清单
   └─ Bug 记录到第六节

3. PR-3 实施后验证
   └─ 用第四节清单 + 三流程推演（第七节）
   └─ Bug 记录到第六节

4. PR-4 实施后验证
   └─ 用第五节清单
   └─ Bug 记录到第六节

5. 所有 PR 验证完 → 统一修 bug（D3）
   └─ BLOCKING / MAJOR 优先
   └─ MINOR / COSMETIC 后修

6. 通过第八节标准 → T1 阶段完成
```
