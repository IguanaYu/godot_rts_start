## 第 2 章 分关详细攻略

### 关卡 1：闪电战 Blitz ⚡

**胜利条件**：依次占领全部 3 个据点
**失败条件**：玩家单位全灭
**胜利脚本**：[victory_blitz.gd](../../scripts/victory/victory_blitz.gd)

**开局资源**
- 金币：0（无法造兵造塔）
- 兵力：3 士兵 + 2 弓兵（玩家） + 3 士兵 + 2 弓兵（AI 盟友，黄色）
- 建筑：无
- 技能：无

**核心机制**
- 每占领一个据点，全军恢复 50% HP
- 每占领一个据点触发增援（具体见 capture_point 奖励配置）
- 没有城堡意味着失败条件不是"建筑被毁"而是"全灭"——容错较高

**推荐打法**
1. **开局 0-15s**：所有人编一队，弓兵手动后置避免冲前
2. **第一据点（约 460px 处）**：弓兵拉到射程边缘poke，士兵抗线；AI 盟友会自动跟战
3. **占完后立刻治疗**：等占点完成再继续推，不要带着残血打下一波
4. **第二/三据点（960px / 1510px）**：敌方弓兵比例上升（5 弓兵），优先集火弓兵
5. **微操要点**：被集火的目标立刻后拉，让敌方切目标浪费输出

**三星路线**：本关 config 未配 star_time，但通关即给星级；建议 0 死亡为目标

### 关卡 2：基础进攻 Basic Attack ⚔️

**胜利条件**：摧毁敌方城堡
**失败条件**：己方城堡被毁
**胜利脚本**：[victory_destroy_base.gd](../../scripts/victory/victory_destroy_base.gd)

**开局资源**
- 金币：默认（开局已有城堡和资源产出）
- 兵力：3 士兵 + 2 弓兵
- 建筑：1 城堡 + 1 兵营
- 可建造：**全 10 项解锁**（士兵/弓兵/枪兵/僧侣 + 全建筑）
- 技能：无

**敌方威胁**
- 5 普通单位 + 1 精英士兵（scale 1.5、+200 HP、+8 攻、移速 ×0.75）
- 1 城堡 + 1 兵营 + 1 靶场 + 2 箭塔

**推荐打法**
1. **开局 0-30s**：城堡附近造 1-2 个箭塔防御，兵营立即开始产弓兵
2. **3 分钟内**：攒到 8-10 弓兵 + 4-5 士兵 + 2 枪兵
3. **拆外围塔**：用枪兵（对塔加成）敲掉敌方 2 座箭塔
4. **决战**：弓兵铺开集火精英士兵（血厚但慢，可以拉扯），士兵顶前吸收伤害
5. **推城堡**：剩余部队 A 上去拆城堡，弓兵掩护

**已知问题**：根据[关卡设计白皮书](关卡设计白皮书.md)诊断，本关敌方兵营距离玩家城堡仅 440px，会被持续产兵压制，建议速攻

### 关卡 3：风暴前线 Storm Front 🌩️

⚠️ **csv 翻译陈旧**：UI 显示"塔防 3 波"，实际是"占 3 点 + 抗 4 波"

**胜利条件**：抗完所有波次 + 清场
**失败条件**：城堡被毁
**胜利脚本**：[victory_survive_waves.gd](../../scripts/victory/victory_survive_waves.gd)

**开局资源**
- 金币：6000
- 兵力：3 士兵 + 2 弓兵
- 建筑：1 城堡 + 1 兵营
- 可建造：士兵 / 弓兵 / 枪兵 / 僧侣 + 城堡 / 兵营 / 靶场 / 修道院 / 城墙
- 技能：[0, 2] = 轨道轰炸 + 护盾墙

**核心机制**
- 占领 3 个普通据点会**削弱最终波**（每点降低敌兵属性或数量）
- 4 波次递增：5 → 9 → 14 → 最终波

**推荐打法**
1. **开局 0-30s**：派 1 士兵去最近的据点开始占领，主力守家造塔
2. **资源分配**：60% 投入箭塔防线（围绕城堡 200-300px 半径），40% 产兵
3. **轨道轰炸**留给第 3 波（14 人）的密集进场瞬间
4. **护盾墙**留给最终波，覆盖城堡前方
5. **3 个据点必须占**：不占最终波会很难打

**三星路线**
- 3★：≤480s 且死亡 ≤3
- 2★：≤600s 且死亡 ≤5
- 关键：开局占点速度要快，主力不要冲出去送

### 关卡 4：神射三杰 Three Sharpshooters 🎯

**胜利条件**：3 名精英弓兵全部到达终点
**失败条件**：任一 VIP 弓兵死亡
**胜利脚本**：[victory_composite.gd](../../scripts/victory/victory_composite.gd)（reach_location + vip_survival）

**开局资源**
- 金币：0
- 兵力：3 VIP 精英弓兵 + 护送单位
- 建筑：无
- 可建造：无（纯微操关）

**核心机制**
- VIP 一死直接失败，不能复活
- 必须到达指定终点区域
- 路上有多组伏兵

**推荐打法**
1. **编队**：3 个 VIP 单独编一队（Ctrl+1），护送队编二队（Ctrl+2）
2. **走位**：护送队始终在 VIP 前方 100-150px，遇敌先接战
3. **VIP 操作**：手动控制射程，打完就后撤
4. **绕路优先**：宁可绕远路也不要硬冲敌方密集区
5. **遇伏**：护送肉盾顶住，VIP 拉到最大射程外输出

**三星路线**
- 3★：≤300s 且 0 死亡 ← 极严苛
- 2★：≤420s 且死亡 ≤2
- 提示：本关地形 theme=2，路径窄，多利用拐角卡位

### 关卡 5：技能觉醒 Skill Awakening ✨

**胜利条件**：抗完 3 波 + 清场
**失败条件**：城堡被毁
**胜利脚本**：[victory_survive_waves.gd](../../scripts/victory/victory_survive_waves.gd)

**开局资源**
- 金币：2000（偏紧）
- 兵力：3 士兵 + 2 弓兵
- 建筑：1 城堡 + 1 兵营
- 可建造：仅士兵 / 弓兵 + 城墙 / 箭塔（4 项）
- 技能：[0, 2] = 轨道轰炸 + 护盾墙

**教学意图**
- 让玩家熟悉两个核心技能的释放节奏
- 资源偏紧逼迫用技能而不是堆兵解决

**推荐打法**
1. **轨道轰炸用法**：等敌兵密集进场（第 2 / 3 波）再放，一发能秒 3-5 个
2. **护盾墙用法**：放在城堡正前方 100px，扛爆发波的关键
3. **兵种选择**：优先弓兵（输出高），士兵只造 2-3 个当肉盾
4. **技能 CD 间隙**：用弓兵+塔补输出

**三星路线**
- 3★：≤360s 且死亡 ≤1
- 2★：≤540s 且死亡 ≤3

### 关卡 6：资源枯竭 Resource Drain 💰

**胜利条件**：摧毁所有敌方建筑
**失败条件**：城堡被毁
**胜利脚本**：[victory_destroy_buildings.gd](../../scripts/victory/victory_destroy_buildings.gd)

**开局资源**
- 金币：1500（极少）
- 兵力：0（无初始单位）
- 建筑：0（无初始建筑）← 极特殊
- 可建造：**仅箭塔(5) + 城墙(6)**
- 技能：[3] = 单位空投

**核心机制**
- 没有兵营不能造兵，唯一的兵源是技能 [3] 空投
- 5 个资源点散布地图，占领后给金币
- 必须用塔推进（塔拆完敌方建筑就赢）

**推荐打法**
1. **开局 0-30s**：在城堡周围造 2 座箭塔 + 城墙封口
2. **空投技巧**：CD 好了立刻用，单位当游击队去占资源点
3. **塔推进**：每占一个资源点就在该位置造 1 座箭塔，逐步压缩敌方空间
4. **资源点防守**：敌方会反扑占点，塔能帮你守
5. **终局**：塔推到敌方建筑前，集火拆掉

**三星路线**
- 3★：≤480s 且 0 死亡（空投单位也不能死）
- 2★：≤600s 且死亡 ≤3

### 关卡 7：古墓防御 Tomb Defense ⚰️

**胜利条件**：抗完 4 波 + 清场
**失败条件**：城堡被毁
**胜利脚本**：[victory_survive_waves.gd](../../scripts/victory/victory_survive_waves.gd)

**开局资源**
- 金币：5000
- 兵力：3 士兵 + 2 弓兵 + 1 僧侣（含治疗）
- 建筑：1 城堡 + 1 兵营 + 1 修道院（产僧侣）+ 1 陵墓
- 可建造：全兵种 + 多数建筑（8 项）
- 技能：[0, 1, 2] = 轨道轰炸 + 治疗领域 + 护盾墙

**核心抉择**
- 每占领一座古墓：得奖励（金币/资源）
- **代价**：后续波次敌人变强（每占一座增强一次）
- 这是一个"占还是不占"的博弈

**推荐打法**
1. **占 1 座古墓**（性价比最高）：拿首份奖励，但不要贪
2. **不占第 2/3 座**：后续波次强度增长比奖励更可怕
3. **僧侣是核心**：保持在队伍中心，所有近战都能享受到治疗
4. **技能组合**：治疗领域 + 护盾墙同时开，能扛过任何爆发波
5. **轨道轰炸**留给最后一波

**三星路线**
- 3★：≤480s 且死亡 ≤2
- 2★：≤600s 且死亡 ≤4

### 关卡 8：拉锯战 Tug of War 🪢

⚠️ **csv 翻译过简**：实际敌方基地有驻军 + 多波次，不是单纯经典 RTS

**胜利条件**：摧毁敌方城堡
**失败条件**：己方城堡被毁
**胜利脚本**：[victory_destroy_base.gd](../../scripts/victory/victory_destroy_base.gd)

**开局资源**
- 金币：6000
- 兵力：动态生成
- 可建造：士兵 / 弓兵 / 枪兵 / 僧侣 + 城堡 / 兵营 / 靶场 / 修道院 + 箭塔
- 技能：[2] = 护盾墙

**核心机制**
- 敌方基地**预先有驻军**
- 还会按波次派援军过来
- 必须先消耗驻军再推主基地

**推荐打法**
1. **龟家期 0-3min**：建 3-4 箭塔 + 城墙防线，攒兵到 15+
2. **消耗驻军**：派小股部队骚扰敌方外围，引出驻军逐一消灭
3. **拆前哨**：先拆外围箭塔/兵营，削弱敌方续战能力
4. **护盾墙留给决战**：推主城堡时开，吸收驻军+援军的合击
5. **不要硬冲**：敌方基地内部队比看起来多

**三星路线**
- 3★：≤600s 且 0 死亡（很苛刻）
- 2★：≤780s 且死亡 ≤5

### 关卡 9：四面围攻 Siege from All Sides 🌀

**胜利条件**：抗完 5 波 + 清场
**失败条件**：城堡被毁
**胜利脚本**：[victory_survive_waves.gd](../../scripts/victory/victory_survive_waves.gd)

**开局资源**
- 金币：8000（开局最富）
- 兵力：动态生成
- 可建造：8 项（同 M8）
- 技能：[1, 2] = 治疗领域 + 护盾墙

**核心机制**
- 5 波敌人从 4 个方向进场
- 每波都有精英单位混编
