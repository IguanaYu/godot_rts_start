## 一、文档定位

T1 阶段聚焦"经济底层 + 骚扰 + SH1 据点"，T2 阶段聚焦"时代升级 + 科技系统 + UI 改造"。本文档承接 T2 完工后的下一个阶段——**T3 时代升级（约 5:00-7:00 启动）+ 终局决战（10:00）+ 长期扩展埋点**。

T3 是 10 分钟 PVE 简化 RTS 的**最后一个核心阶段**，承担三重使命：
1. **终局玩法**：给玩家"升满本"的回报感
2. **决战时刻**：10 分钟到点的胜负判定
3. **扩展埋点**：为局外成长 / 新关卡 / 多周目留接口

⚠️ 本文档的所有内容**等 T2 实施完成后**再启动，本阶段先做设计沉淀。

## 二、范围与边界

### 2.1 T3 阶段做什么

- T3 时代升级机制（T2→T3 的花金币升级流程）
- T3 解锁内容清单（建筑、单位、科技）
- T3 阶段科技树延伸（单位特色升级 T3 高级数值、新单位特色）
- T3 阶段骚扰延续 & 终局决战（第 7-8 波 + BOSS）

- 经济后期平衡（农场 +30% 后的金币压力）

- 指挥官系统扩展（属于阶段 5，T3 仅复用现有指挥官）

- 大战术释放具体实现（独立模块，T3 仅复用为 BOSS）
- 局外成长具体实现（长期扩展，T3 仅留接口）

## 三、从 T1/T2 沉淀的方法论（约束 T3 设计）

以下方法论已在 T1/T2 阶段拍板，T3 设计必须延续或显式打破。

### 3.1 阶段定义方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **事件驱动定义阶段**（非时间窗口）| T2 A 模块 | T3 阶段 = "启动 T3 升级" → "游戏结束"（而非"5-7 分钟"固定窗口）|
| **玩家自选升级时机**（推荐区间但不强制）| T2 A 模块 | T3 推荐时机 ~5:00-7:00，但允许玩家速 T3 / 龟缩不升 |
| **战略路径多样化**（速攻 / 平稳 / 龟缩）| T2 A 模块 | T3 需支持"速 T3 抢高级 / 平稳过渡 / 龟缩防守"3 种路径 |

### 3.2 升级机制方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **花金币 + 时间升级**（不走纯被动）| T2 决策 1 | T3 升级也是花金币 + 时间 |
| **升级中城堡完全正常**（产金照常 / HP 不变）| T2 B 模块 | T3 沿用（"完全正常"等价于"产金照常"，因为城堡不产兵）|
| **可取消全额退款** | T2 B 模块 | T3 沿用，给玩家灵活度应对骚扰 |
| **升级反还金币**（启动后续建设的桥梁）| T2 B 模块 | T3 也需算账：升级反还应让玩家能立刻启动 T3 新建筑/单位 |

### 3.3 经济与数值方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **双兵营主流**（T1 鼓励 2 兵营）| T2 A 模块 | T3 阶段玩家已有 2 兵营 + 1 靶场 + 农场的基础 |
| **步兵 50 金 + 弓兵 100 金**（脆皮远程贵）| T2 C 模块 | T3 新单位造价需对照（一般 >100 金，体现高级）|
| **百分比加成**（HP/DMG/SPD 都是 +10%/级）| T2 D 模块 | T3 新单位特色升级也走百分比 |
| **通用升级 1.5x，单位升级 1x** | T2 D 模块 | T3 若引入新通用升级节点，沿用 1.5x 倍率 |
| **农场/城堡科技单次升级**（不做多级）| T2 D 模块 | T3 若引入新建筑科技，沿用"单次"哲学 |

### 3.4 科技树方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **3 层科技树**（通用 / 单位基础 / 单位特色）| T2 D 模块 | T3 新单位也需挂"单位基础 + 单位特色"两套升级 |
| **单位特色 T1/T2/T3 三级递增解锁**（500/700/1000 金）| T2 D 模块 | T3 阶段解锁特色升级"高级"档（1000 金）|
| **27 个升级节点**（T2 阶段玩家升 3-5 个）| T2 D 模块 | T3 总节点数控制（避免爆炸，建议 T3 阶段新增 < 15 个）|

### 3.5 UI 方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **底部横排三段式**（QW + 详情 + 小地图）| T2 F 模块（08-07 修正）| T3 不动布局，沿用底部横排 |
| **不分类大网格 + 灰色锁统一展示**| T2 F/G 模块 | T3 新解锁项也加入 QW 网格，按时代顺序排列 |
| **升级按钮视觉**：名称 + 当前等级 + 费用 | T2 F 模块 | T3 沿用，1000 金的高级升级按钮需特别视觉处理 |
| **选中高亮维持现状光圈** | T2 F 模块 | T3 不引入新选中效果 |
| **整体低调设计哲学** | T2 G 模块 | T3 升级启动 / 完成也低调反馈，唯一显眼的是终局 BOSS |

### 3.6 骚扰与节奏方法

| 方法论 | 来源 | T3 应用 |
|---|---|---|
| **骚扰时间驱动**（3:30 / 5:30 / 7:30）| T1/T2 E 模块 | T3 延续：第 7 波 8:30 / 第 8 波 9:30 / 终局 10:00 |
| **骚扰 DPS 曲线递增** | T1/T2 E 模块 | T3 延续递增曲线，终局 BOSS 单独算 DPS |
| **骚扰与升本独立运作** | T2 E 模块 | T3 阶段骚扰不因升 T3 而变化 |
| **每波新加入单位类型**（第 3 波加弓兵）| T2 E 模块 | T3 阶段骚扰方加入 T3 单位（具体待 C 模块定）|
| **10 分钟 PVE 节奏**（玩家无暇培养单兵）| T2 决策 4 | T3 不能引入需要"长时间培养"的机制（如单兵升级）|

## 八、已识别的风险与未决问题

### 风险 1：T3 阶段时间太短

10 分钟游戏，T3 升级 ~5:00-7:00 启动 + 30-60s 升级时间 → 实际 T3 阶段只剩 3-4 分钟。这 3-4 分钟要装下"建 T3 建筑 + 造 T3 单位 + 升级 + 决战"，节奏会很紧。

**缓解方案**：
- T3 单位建造/产能要快（参考 T2 弓兵 20s）
- T3 升级反还金币让玩家立刻能启动建设
- 决战触发后不再有骚扰间隙

### 风险 2：玩家升不动 T3

如果骚扰压力大，玩家可能根本攒不到 T3 升级费（假设 1000 金）。

**缓解方案**：
- T3 升级费用不能太高（建议 700-1000 金，不超过 T2 太多）
- 反还金币让升级"实际开销"低于"标价"
- "龟缩 T2"也是有效玩法路径

### 风险 3：T3 内容太多玩家玩不完

如果 T3 解锁 3 个新单位 + 5 个新升级，玩家 3-4 分钟玩不完。

**缓解方案**：
- T3 解锁内容控制在 1-2 个新单位 + 2-4 个新升级
- 新单位特色升级与 T1/T2 共用单位特色升级线（T3 高级档）
- 玩家不必升满 T3 也能通关（设计冗余）

### 风险 4：终局 BOSS 难度难调

"大战术释放者"现有数值（scale 1.2 / HP 2000 / 4 tactic）是为"独立挑战"设计，作为终局 BOSS 可能过强或过弱。

**缓解方案**：
- 终局 BOSS 与现有"大战术释放者"解耦，新设计或参数微调
- 决战触发时间弹性（玩家弱时推迟 / 玩家强时提前）
