### 4.2 关键实现要点

#### A. 复制 WALL → FARM（不要破坏 WALL）

**关键点**：所有改动**新增 FARM 项**，不要修改 WALL 的任何代码。

**D16 决策**：FARM 接 PlaceMode 末尾（ENCHANTER 之后），不动现有 enum 值。加分组注释提高可读性：

```gdscript
    NONE, WALL, TOWER, CASTLE, BARRACKS,
```

```gdscript

const BUILD_RADIUS := 6 * 64  # 384 px

func is_in_buildable_area(pos: Vector2) -> bool:
    # D3 中心点法：待放格子中心到主基地距离 ≤ 384px 即可建

    return pos.distance_to(main_node.player_castle.position) <= BUILD_RADIUS
```

### 7.1 PR-1 调研结论（已敲定）

#### Q-1：SaveManager 临时 flag 机制

**现状**：不存在 temp_flag 机制。SaveManager 只做持久化（`user://saves/slot_%d.json`）。

**相关 API（[save_manager.gd](../../scripts/systems/save_manager.gd)）**：
- `enter_default_slot()` / `set_current_slot(slot)` / `get_current_data()`
- `is_commander_unlocked(cmd_id)` / `unlock_commander(cmd_id)`
- `set_last_selected_commander(cmd_id)` / `get_last_selected_commander()`
- `start_game_session(level_id)` / `end_game_session(result, difficulty)`

**CommanderChoice（[commander_choice.gd](../../scripts/commander/commander_choice.gd)）**：
- `player_selected_id: StringName = &"balanced"`（核心字段）
- `select_commander()`（UI 写入）
- `set_pending_level(scene_path, level_id)`（关卡路径传递）
- main.gd:186 读 `player_selected_id`；main.gd:112 读 loadout

**map_config 注入路径**：main.gd:11 `@export var map_config`，场景实例化时由外部注入；没有"指定路径直接进入"API。

**LoadRouter（[load_router.gd](../../scripts/systems/load_router.gd)）**：
- `LoadRouter.request_load(scene_path, is_multiplayer)` —— 现成的异步场景加载入口（含进度条），可复用。

**PR-1 设计方案**：在 [save_manager.gd](../../scripts/systems/save_manager.gd) 新增会话级临时存储：
```gdscript
var _temp_flags: Dictionary = {}  # 不持久化，仅本会话有效

func set_temp_flag(key: String, value: Variant) -> void:
    _temp_flags[key] = value

func get_temp_flag(key: String, default: Variant = null) -> Variant:
    return _temp_flags.get(key, default)

func clear_temp_flags() -> void:
    _temp_flags.clear()
```

**T1 测试入口流程**（复用现有路径 + 最小改动）：
```
主菜单"T1 测试"按钮
  → SaveManager.set_temp_flag("skip_loadout_screen", true)
  → SaveManager.set_temp_flag("force_commander", "test_all")
  → CommanderChoice.set_pending_level("res://scenes/maps/map_t1_economy_test.tscn", "t1_test")
  → LoadRouter.request_load("res://scenes/main.tscn", false)
main.gd 启动时:
  → if SaveManager.get_temp_flag("skip_loadout_screen", false):
        CommanderChoice.player_selected_id = SaveManager.get_temp_flag("force_commander")
        _selected_loadout = [FARM, TOWER, BARRACKS, SOLDIER, ARCHER]
        跳过 commander_select 界面
```
