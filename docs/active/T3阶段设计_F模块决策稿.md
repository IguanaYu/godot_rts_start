## 五、胜利统计画面（F5，G4 具体化）

### 显示项清单

| 类别 | 项 |
|---|---|
| 时间 | 用时（游戏开始到摧毁据点的总时间）|
| 经济 | 剩余金币 / **获得金币数**（总收入）|
| 战斗 | **击杀数**（敌方单位 + 建筑）/ **死亡单位数量** |
| 建设 | **玩家建造的单位数** / **玩家建造的建筑数** |
| 单位明细 | **每个单位造成的伤害总量**（如果数据可追踪）|

### 综合得分

**计算公式**（待数值校准）：
- 综合 = 造单位数 + 造建筑数 + 击杀数 + 获得金币数 + ...

**取舍**：时间越长得分越高（用户明确表态"没事这样"），不强行鼓励速通。
