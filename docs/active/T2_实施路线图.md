### 4.2 关键依赖说明

- **PR-T2-3 不依赖 PR-T2-1/2**：UI 框架和详情面板基础切换可独立做，时代升级状态由 PR-T2-1 提供，PR-T2-3 直接读状态即可。

- **PR-T2-5 QW 灰色锁必须等 PR-T2-1**：灰色锁的"是否解锁"状态来自时代升级机制。
- **PR-T2-5 QW 灰色锁必须等 PR-T2-4**：升级节点的"当前等级"也要在 QW 网格里反映。

### PR-T2-4：兵种全局升级系统（⏳ 待启动）

**核心交付**：
- `unit_upgrade_manager.gd`（新建，管理兵种全局等级 + 升级触发 + 全单位属性更新）
- 31 个升级节点 .tres 配置（设计文档原说 27 个，按 5 类清单实际算下来 31 个）：
  - 通用升级 3 条线 × 3 级（HP+10% / DMG+10% / SPD+10%，1.5x 费用 300/600/900）
  - 单位基础升级 步兵 + 弓兵 各 2 条线 × 3 级（HP+10% / DMG+10%，1x 费用 200/400/600）
  - 单位特色升级 步兵回血（T1/T2/T3 三级 500/700/1000，每 5s 回 1%/5%/10%）
  - 单位特色升级 弓兵减速箭（T1/T2/T3 三级 500/700/1000，减速 10%/20%/30% / 1s/2s/3s）
  - 农场科技 1 个（产量 +30%，单次 500 金）
  - 城堡科技 3 个（箭塔 +20% / 血量 +20% / 兵营造速 +20%，各 500 金单次）
- 升级 UI 接入详情面板：升级按钮视觉 = 名称 + 当前等级 + 费用（如"步兵 HP+ 2/3 → 400 金"）
- 升级触发：即时生效（扣金币 + 等级+1 + 全单位属性更新，无研究时间）
- 隐藏单兵升级 UI（保留代码，未来"老兵系统"激活）

- [ ] 升级后所有现有 + 未来该兵种单位属性变化
- [ ] 升级按钮显示当前等级和下级费用
- [ ] 满级（3/3）后按钮变灰
- [ ] 通用升级同时影响步兵+弓兵
- [ ] 单位特色升级 T1/T2/T3 分级解锁
- [ ] 农场/城堡科技单次升级后消失
