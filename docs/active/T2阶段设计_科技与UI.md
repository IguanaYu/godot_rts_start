## 四、已初步拍板的核心决策

### 决策 1：T2 升级机制 = 主动花金币 + 时间

- ❌ 不走纯被动积累（科技点系统）
- ❌ 不走纯金币升级（浪费科技点）
- ✅ **花金币升级**：玩家主动触发，扣金币 + 升级时间

⚠️ 科技点系统的命运待定（候选：废弃 / 作为"加速升级"的辅助资源 / 作为"升级解锁"的门槛）

### 决策 2：T2 解锁内容 = 靶场 + 弓兵

- T2 解锁建筑：**靶场**（ARCHERY_RANGE）
- T2 解锁单位：**弓兵**（ARCHER）
- 一本只有近战步兵，二本引入远程弓兵（火力分层）
- 未来 T2 单位候选：长矛兵、僧侣、持盾兵等（每个建筑系统对应一个核心单位）

### 决策 3：T1 内容的命运 = 保留 + 共存

- T1 步兵在 T2 仍可造（来自兵营）
- T2 解锁弓兵（来自靶场）
- 多种兵种组合搭配（步兵抗线 + 弓兵输出）

### 决策 4：兵种全局升级 = 取代单兵升级

- T1/T2 阶段只做**兵种全局升级**（花一笔钱，所有该兵种单位 + 等级）
- 单兵升级系统**保留代码但隐藏 UI**
- 未来"场地养老兵"机制（如据点驻守加经验）可能激活单兵升级，留作延展

#### 兵种全局升级参数

| 参数 | 值 |
|---|---|
| 最高等级 | 3 级 |
| 每级加成 | +10 HP / +2 DMG / +5 SPD（步兵基础；其他兵种微调）|
| 费用曲线 | 200 / 400 / 600 金（递增）|
| 触发方式 | 即时生效（无研究时间）|
| 影响范围 | 所有现有 + 未来该兵种单位 |

## 五、建造栏 UI 设计（右侧统一信息柱）

### 核心设计：三段式信息柱

把现有分散的 UI 元素（目标面板右上角 + 小地图右下角）整合到屏幕右侧，形成"统一信息柱"。

### 视觉布局

```
┌────────────────────────────────────────┐
│ 资源(左上)                              │
│                                ┌──────┐│
│                                │目标  ││ ← 顶部 15%
│        [游戏世界]              │波次  ││
│                                ├──────┤│
│                                │详情  ││ ← 中部 55%
│                                │面板  ││   （主要操作区）
│                                │      ││
│                                │      ││
│                                ├──────┤│
│                                │小地图││ ← 底部 30%
│        ┌──────────────┐        │      ││
│        │ QW 建造栏     │        │      ││
│        └──────────────┘        └──────┘│
└────────────────────────────────────────┘
```

### 三段式高度分配

| 区域 | 高度占比 | 内容 |
|---|---|---|
| **目标面板** | 15% | 波次倒计时 + 胜利条件进度 |
| **详情面板** | 55% | 选中对象的现状 + 科技升级 |
| **小地图** | 30% | 战场缩略图 |

### QW 建造栏变化

- **变矮**（信息密度降低，因为详情移到右侧）
- **保留**：tab + 1 行图标 + 时间条（3 层结构）
- **点击行为不变**：QW 一键建造/造兵

## 七、时代升级机制详细设计

### 升级流程

1. 玩家点击地图上的城堡（或 QW 默认显示城堡详情）
2. 详情面板显示"升级到 T2"按钮
3. 玩家点击升级 → 检查金币 + 前置
4. 扣金币（500 金）
5. 城堡进入"升级中"状态（15s 倒计时）
6. 升级完成 → 反还 300 金 + T2 解锁（靶场可建、弓兵可造）

### 升级参数（B 模块已拍板 2026-08-04）

| 时代 | 金币 | 时间 | 反还 | 解锁内容 |
|---|---|---|---|---|
| T1 → T2 | **500** | **15s** | **300 金** | 靶场、弓兵、T2 兵种全局升级 |
| T2 → T3 | ⏳ 推到 T3 阶段聊 | - | - | 修道院、僧侣、T3 兵种、特殊单位 |

### 升级中的城堡状态

**已拍板**：**完全正常**——产金照常、HP 不变、无任何负面影响。

注：当前城堡本来就不产兵（产兵由兵营/靶场负责），所以"完全正常"等价于"产金照常"。

### 升级可否取消

**已拍板**：**可取消全额退款**——玩家可在升级期间随时取消，退还 100% 金币。

设计意图：给玩家灵活度，应对骚扰压力时可以"取消升级 → 用钱补兵 → 防守 → 再升"。10 分钟 PVE 节奏下，exploit 风险可接受。

### 升级失败条件

- 城堡在升级期间被摧毁 → 游戏失败（沿用现有规则）
- 升级期间取消 → 退全款，无失败惩罚

## 十一、关键设计决策（汇总）

| # | 决策 | 理由 |
|---|---|---|
| 1 | T2 升级主动花金币 | 玩家有决策点，符合传统 RTS |
| 2 | T2 解锁靶场 + 弓兵 | 一本全近战，二本引入远程，火力分层 |
| 3 | T1 单位保留 | 多兵种组合，不是替代 |
| 4 | 兵种全局升级取代单兵 | 10 分钟游戏节奏紧，无暇培养单兵 |
| 5 | 升级最高 3 级 | 数值可控，决策清晰 |
| 6 | 升级费用 200/400/600 | 早期可升 1 级，后期升满是重大投资 |
| 7 | 即时生效（无研究时间）| 节奏紧凑，避免焦虑 |
| 8 | 右侧三段式信息柱 | 经典 RTS 布局，视野最大化 |
| 9 | 时代升级挂城堡详情 | 主基地是时代象征，逻辑自洽 |
| 10 | 详情面板 hover 临时切换 | 玩家无成本浏览，不丢失选中 |
