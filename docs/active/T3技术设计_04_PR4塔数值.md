## 一、本 PR 目标

按 A 决策稿 Q3 调整塔的数值：

| 项 | 改前 | 改后 | 理由 |
|---|---|---|---|
| 基础造价 | 150 金 | **180 金** | 略上调，让前 1-2 座性价比仍明显 |
| 递增造价 | 无 | **每多 1 座 +50 金** | 防塔海（第 3 座 280 / 第 4 座 330 / ...） |
| 攻击范围 | 150 | **220** | 让 1-2 座塔能覆盖关键区域 |
| HP | 150 | **180** | 略提升生存 |
| DMG | 12 | **14** | DPS 8 → 10.8 |
| 攻速（CD） | 1.5s | 1.5s（不动） | 决策稿保持 |

**设计意图**：前 1-2 座塔性价比明显（新手能守住），第 3+ 座性价比骤降（防塔海）。

### 2.2 改 `scripts/systems/game_data.gd` COSTS 字典（同步基础造价）

**位置**：[game_data.gd:25](../../scripts/systems/game_data.gd#L25)

```gdscript
PlaceMode.TOWER: 180,  # 改前 150
```

**为什么两个地方都要改**：
- `tower_stats.tres` 的 `cost_override` 用于 `building_placer.get_current_cost` 计算最终造价（基础 + 递增）
- `game_data.gd` 的 `COSTS` 用于按钮显示和初始检查

**验证**：搜代码确认 `building_placer.get_current_cost` 优先用哪个。从 PR-4 调研看，[`get_current_cost` L107-118](../../scripts/systems/building_placer.gd#L107)：
```gdscript
var base: int = D.COSTS.get(mode, 0)
var bt: int = D.PLACE_MODE_TO_BUILDING.get(mode, -1)
if bt < 0:
    return base
var stats = BuildingStatsRegistry.get_by_type(bt)
if stats == null or stats.cost_increment <= 0:
    return base
```

**关键发现**：base 来自 `D.COSTS`（game_data.gd），递增来自 stats.cost_increment。所以 `cost_override` 字段名可能是用于其他地方（如详情面板显示）。**两个地方都改成 180 是安全做法**。

## 三、机制说明：递增造价如何生效

### 现有流程

```
玩家点建造按钮
  ↓
main._on_place_mode_requested
  ↓
building_placer.check_build_block(place_mode, click_pos)
  ↓ 内部调用 get_current_cost(mode) 计算实际造价
  ↓
金币检查：gold >= get_current_cost(mode)
  ↓ 通过则放置
```

### 现有递增公式

```
actual_cost = base_cost + count_of_same_type * cost_increment
```

例：塔的 base = 180 / cost_increment = 50
- 第 1 座：180 金（count=0）
- 第 2 座：230 金（count=1）
- 第 3 座：280 金（count=2）
- 第 4 座：330 金（count=3）
- 第 5 座：380 金（count=4）

## 四、测试要点

### 4.1 数值生效

1. 进游戏，选中建造塔（QW 网格）
2. **验证**：按钮显示"180 金"（不再是 150）
3. 放置第 1 座塔 → 扣 180 金
4. 再放第 2 座 → 扣 230 金
5. 再放第 3 座 → 扣 280 金
6. 选中塔，**验证**：HP 180 / DMG 14 / 射程 220

### 4.2 战斗表现

1. 让敌方单位进入塔范围
2. **验证**：塔在 220 范围内开始攻击
3. **验证**：每次命中造成 14 伤害
4. **验证**：1.5s 攻击间隔

### 4.3 防塔海

1. 攒够 2000 金
2. 尝试连造 5 座塔
3. **验证**：5 座塔总造价 = 180+230+280+330+380 = 1400 金
4. 第 6 座会要 430 金，玩家应该感受到"不划算"
