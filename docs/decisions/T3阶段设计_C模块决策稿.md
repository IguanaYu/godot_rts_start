## 一、时代解锁结构调整（🔥 重大调整）

| 时代 | 单位 | 建筑 |
|---|---|---|
| **T1** | 步兵 | 兵营、塔、墙、农场、城堡 |
| **T2** | 弓兵 + **僧侣**（新增 T2 解锁）| 靶场 + **修道院**（新增 T2 解锁）|
| **T3** | **长矛兵**（挪到 T3 解锁）| **T3 学院** + **长矛兵营**（2 个新建筑）|

**意图**：T2 阶段玩家就有 3 兵种搭配（步+弓+僧侣），4 条核心战略路径在 T2 阶段已经差异化。

**代码改动方向**：
- `_init_unlocked_items` 从 T1 默认 unlocked_items 中剔除 MONK_UNIT / MONASTERY / LANCER
- `_unlock_age_items(age>=2)` 加 MONASTERY + MONK_UNIT
- `_unlock_age_items(age>=3)` 加 LANCER + T3_ACADEMY + LANCER_BARRACKS

## 二、T3 升级方案（4 兵种 N 选 1）

### 升级形式：混合（每兵种独立设计）

### 步兵 2 选 1（类型转化）

| 选项 | 数值调整 | 新机制 | 定位 |
|---|---|---|---|
| **A. 狂战士** ⚔️ | HP -20% / DMG +50% / 攻速 +30% | **血怒**：HP<30% 时攻速额外 +50% | 高风险高输出 |
| **B. 盾卫** 🛡️ | HP +100% / DMG -20% / 攻速 -20% | **盾墙**：受伤 -30% / **嘲讽**：强制敌人攻击自己 | 极致生存+拉仇恨 |

### 弓兵 3 选 1

| 选项 | 数值调整 | 新机制 | 定位 |
|---|---|---|---|
| **A. 神射手** | DMG +30% / 射程 +20% / 暴击 +15% | 无 | 纯远程 DPS |
| **B. 近战杀手** | DMG 不变 | **针对性**：对近战单位 +50% DMG | 克制近战多的敌阵 |
| **C. 减速射手** | DMG -20% | **缓速箭**：减攻速 15%（叠加 3 层到 -45%）+ 减移速 15% | 风筝+控场 |

| **B. 祝福者** 💫 | 治疗量 -50% | **强祝福**：给单一目标 +50% DMG / +30% 攻速（持续 10s / 冷却 5s）| 单点增益 |

| 项 | 开销 |
|---|---|
| T3 升级 | 1000 金 |
| T3 学院 | 300 金 |

- T3 阶段（3-4 分钟）玩家平均能再攒 ~2500-3000 金

- **玩家肯定升不齐 4 项 T3 升级**，必须取舍
