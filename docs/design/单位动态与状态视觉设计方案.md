# 单位动态与状态视觉设计方案

## 目标

在不新增单位贴图、骨骼或逐帧动画的前提下，增强当前 RTS 单位的动作重量、攻击命中感和状态可读性。

本方案建立在已有单位序列帧之上：不替代 `idle / run / attack`，只补足状态切换与战斗反馈。

## 项目现状

- `scripts/units/unit.gd` 已为剑士、弓箭手、枪骑兵和僧侣加载待机、跑动、攻击贴图；前三者已经有攻击序列帧。
- `BodySprite` 已经使用每单位独立的 `ShaderMaterial`，材质来自 `shaders/unit_effects.gdshader`。
- Shader 已支持选中描边、减速染色、受击白闪、狂暴和祝福等 uniform；其中受击白闪尚未接到 `take_damage()`。
- 单位已有选择圈、血条、蓝条、状态色点、治疗特效、精英光环、出生效果和死亡缩小。
- 护盾、中毒、减速、隐身、治疗、增益等游戏状态已经存在，但大多缺少统一的世界内视觉反馈。

## 核心策略

单位的主动画已经由序列帧承担，新增表现仅负责三类信息：

```text
冲量：攻击、命中、停止时的短促位移或缩放
状态：护盾、减速、中毒、治疗、隐身等持续效果
意图：选中、移动、攻击、受控时让玩家看懂单位在做什么
```

不要用夸张果冻替代现有攻击帧。中世纪单位应表现为“重量、后坐、冲刺、受击”，不是软体。

## 视觉层级

```text
CharacterBody2D             # 位置、碰撞、导航，不做视觉缩放
├─ ShadowComponent           # 地面影子
├─ HealthComponent
├─ BodySprite                # 序列帧 + ShaderMaterial；唯一可形变主体
├─ UnitVisualFeedback        # 新增纯表现组件，驱动 BodySprite 与地面绘制
├─ SelectionRing
├─ HPBar / ManaBar
├─ PathLine / AggroLine
└─ 技能组件
```

禁止对 `CharacterBody2D` 本体做攻击或受击缩放/位移：那会连带碰撞、选择圈、血条和寻路表现。所有冲量只写入 `BodySprite.position`、`BodySprite.scale`，地面效果由 `UnitVisualFeedback` 自己绘制。

## 状态设计

| 状态 | 现有来源 | 建议表现 | 备注 |
| --- | --- | --- | --- |
| 出生 | 单位创建、出生光柱 | 轻微落地回弹；保留现有光柱 | 一次性 |
| 待机 / 警戒 | `GUARD` | 不额外抖动；仅使用现有 idle 帧 | 保持战场安静 |
| 移动 | `velocity`、run 帧 | 保持现有 run；停止时有一次极轻落地回正 | 不叠加持续弹跳 |
| 攻击前摇 | `_perform_attack()` | 近战向目标压低/前探；远程略后拉 | 0.06–0.10 秒 |
| 攻击释放 | 命中或投射物生成 | 近战前冲；远程后坐 | 0.10–0.18 秒 |
| 普通受击 | `take_damage()` 造成生命伤害 | 白闪 + 朝受击反方向偏移 2–3 px | 使用已有 shader uniform |
| 护盾承伤 | `take_damage()` 被护盾完全吸收 | 蓝白小环，禁止白闪 | 明确“没掉血” |
| 治疗 | `heal()` | 保留 HealEffect，身体向上轻提再回正 | 一次性 |
| 减速 | `apply_slow()` | 保留冰蓝 tint；脚下蓝色短环 | 不新增贴图 |
| 中毒 | `apply_poison()` | 绿色低频闪点 / 脚下小点环 | 与减速不能只靠颜色区分 |
| 护盾存在 | `_shield_hp > 0` | 半透明蓝白细环，低频呼吸 | 不遮住单位 |
| 隐身 | `StealthEffect` | 保留现有 alpha；不额外高亮 | 避免暴露单位 |
| 增益 / 光环 | `buffs`、精英光环 | 保留现有狂暴/祝福 tint；只给关键单位加环 | 避免全军特效化 |
| 选中 | `selected` | 保留现有描边与选择圈 | 不重复造轮子 |
| 死亡 | `die()` | 保留当前缩小和死亡逻辑 | 第一阶段不改 |

## 兵种动作配置

| 兵种 | 主动画 | 新增冲量 | 禁止事项 |
| --- | --- | --- | --- |
| 剑士 | Idle / Run / Attack | 攻击向目标前探 3 px；受击后退 2 px | 不整体横向拉伸成橡皮 |
| 弓箭手 | Idle / Run / Shoot | 射出时向目标反方向后坐 2 px | 不叠加假拉弓，现有 Shoot 帧已表达 |
| 枪骑兵 | Idle / Run / Attack | 攻击前探 4 px，短暂停顿后回正 | 不在持续移动中反复前冲 |
| 僧侣 | Idle / Run；治疗特效 | 治疗时向上提 2 px，再缓落 | 不伪造近战攻击动画 |
| 法师 / 未来施法者 | 未来复用 | 蓄力缩小 1%，释放回弹；保留法术本体特效 | 不让本体盖过技能特效 |

所有变体继承 `unit_type` 的默认配置；只有真正特殊的 Boss、召唤物或精英单位才覆盖配置。

## 新组件

新增 `scripts/effects/unit_visual_feedback.gd`，作为 `UnitVisualFeedback` 子节点挂在 `scenes/units/unit.tscn`。

组件只做表现，不能影响 `velocity`、`state`、伤害、护盾、技能 CD 或联网数据。

### 建议接口

```gdscript
func configure(body: Sprite2D, material: ShaderMaterial, unit_type: int, seed: int) -> void
func set_motion(velocity: Vector2, is_running: bool) -> void
func play_spawn() -> void
func play_attack(aim_direction: Vector2, is_ranged: bool) -> void
func play_hit(from_direction: Vector2, shield_absorbed: bool) -> void
func play_heal() -> void
func set_slow(active: bool) -> void
func set_poison(active: bool) -> void
func set_shield(active: bool, ratio: float = 1.0) -> void
func set_stealthed(active: bool) -> void
func set_blessed(active: bool) -> void
func set_enraged(active: bool) -> void
func stop_all() -> void
```

### 内部合成规则

组件缓存 `BodySprite` 的基础 `position` 和 `scale`，将持续状态与短事件相加后一次写回。

```text
最终位置 = base_position + move_settle_offset + attack_offset + hit_offset
最终缩放 = base_scale × idle_scale × attack_scale × hit_scale
```

这样攻击、受击、停止不会争夺多个 Tween，也不会破坏单位场景中不同兵种的初始缩放。

持续状态与短事件分离：

```text
持续状态：idle / moving / slowed / poisoned / shielded / stealthed
短事件：spawn / attack / hit / shield_hit / heal
```

同一时刻允许攻击与受击相加；死亡时调用 `stop_all()` 并停止所有表现。

## Shader 方案

优先复用 `shaders/unit_effects.gdshader`，不要为每个单位创建新 shader 文件。

已有能力：

```text
outline_enabled      选中描边
slow_enabled         冰蓝减速 tint
hit_flash_enabled    受击白闪
enraged_enabled      狂暴红 tint
blessed_enabled      祝福金 tint
```

第一阶段只需把现有 `hit_flash_enabled` 接入：

```text
普通命中：hit_flash_amount 0 → 0.85 → 0，约 0.12 秒
护盾命中：不触发白闪，改为 UnitVisualFeedback 的蓝白地面环
```

由于 `unit.gd` 已在 `_init_outline_materials()` 中为每个单位创建独立材质，动态调整 uniform 不会污染其他单位。

## 地面状态标记

由 `UnitVisualFeedback._draw()` 画极简图形，不使用新贴图：

| 状态 | 图形 | 节奏 |
| --- | --- | --- |
| 护盾 | 蓝白细环 | 1.2 秒呼吸一次 |
| 减速 | 低透明蓝色弧线 | 静止或极慢转动 |
| 中毒 | 3 个绿色小点绕脚底移动 | 低频 |
| 治疗触发 | 一次绿色扩散圆 | 0.25 秒结束 |
| 精英 / 祝福 | 复用现有精英光环或金色细环 | 仅关键单位 |

规则：同一单位同时有多个状态时，最多画两层。优先级为：`护盾 > 中毒 > 减速 > 增益`。

## 现有代码接入点

| 文件 / 方法 | 接入 |
| --- | --- |
| `scenes/units/unit.tscn` | 增加 `UnitVisualFeedback` 子节点并挂脚本 |
| `unit.gd::_ready()` | 在 `_init_outline_materials()` 后调用 `configure()` |
| `unit.gd::_physics_process()` | 将当前 `velocity` 与 run 状态传给 `set_motion()` |
| `unit.gd::_perform_attack()` | 依据目标方向和远程类型调用 `play_attack()` |
| `unit.gd::take_damage()` | 护盾结算后区分普通命中 / 护盾命中，调用 `play_hit()` |
| `unit.gd::heal()` | 保留 HealEffect，额外调用 `play_heal()` |
| `unit.gd::apply_slow()` | 启动减速视觉 |
| 减速到期处 | 停止减速视觉 |
| `unit.gd::apply_poison()` | 启动中毒视觉 |
| 中毒到期 / `cleanse_debuffs()` | 停止中毒视觉 |
| `unit.gd::set_shield_hp()` | 更新护盾环 |
| `unit.gd::die()` | 先调用 `stop_all()`，保留既有死亡动画 |

`StealthEffect` 当前直接修改 Unit 根节点透明度；第一阶段不从 `UnitVisualFeedback` 改写 alpha，避免组件冲突。它只需不绘制额外状态环。

## 性能规则

- 不在单位持续移动时创建 Tween；移动状态用组件内部插值完成。
- 每次攻击、受击最多一个短事件；新事件覆盖同类旧事件。
- 地面环用 `queue_redraw()`，只在状态变化或有可见环时刷新。
- 远离镜头或未选中的普通单位，可关闭中毒点环，只保留 shader tint。
- 不增加每帧粒子；现有 HealEffect、出生、爆炸仍只在事件发生时实例化。

## 编辑器配置

默认按 `unit_type` 自动选配置。只有特殊单位需要在 `UnitVisualFeedback` Inspector 覆盖：

```text
attack_lunge_px：近战前探距离，剑士 3，枪骑兵 4，弓箭手 0
ranged_recoil_px：远程后坐距离，弓箭手 2
hit_push_px：普通受击位移，默认 2
body_pulse_strength：攻击 / 治疗时缩放，0.005 ~ 0.02
status_ring_enabled：是否显示地面状态环
status_ring_radius：默认 16 ~ 22 px
```

## 实施顺序

1. 新增并挂载 `UnitVisualFeedback`，只接普通受击白闪和受击偏移。
2. 将已有 `hit_flash_enabled` 接到 `take_damage()`；区分护盾命中。
3. 接入剑士、弓箭手和枪骑兵的攻击冲量。
4. 接入治疗、减速、护盾和中毒的世界内状态标记。
5. 为精英、Boss、法术单位按需覆盖配置。

## 验收标准

- 剑士、弓箭手、枪骑兵原有序列帧正常播放，且新反馈不改变碰撞或导航。
- 普通命中可见白闪和轻微冲量；护盾吸收时能看出“没有掉血”。
- 同屏大量移动单位没有持续 Tween、粒子爆量或缩放漂移。
- 减速、中毒、护盾至少可在常用 RTS 镜头下分辨两种以上。
- 隐身、选中描边、现有治疗和精英光环不被新组件覆盖。
- 单位死亡后所有临时表现停止，且保持现有死亡逻辑。

## 后续扩展

未来异怪、召唤物与法师可复用同一接口：只覆盖单位配置与状态颜色，不修改战斗状态机。软体怪可以把 `attack_lunge` 和 `hit_push` 的缩放幅度提高，普通人类兵仍维持木石般的重量感。
