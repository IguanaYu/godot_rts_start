# 游戏概览

> 回答"这是个什么游戏"。接手任何设计讨论前先读本文。
> 内容过时或不准确时随时修正——这是活文档。

## 一句话定位

单机为主的**进攻向像素风 RTS**：玩家（+AI 队友）从零建起经济与部队，逐个拔掉敌方据点，最终摧毁敌方基地获胜。参考方向是星际2合作模式/PVE 向的"打据点"体验，而非对称 PvP。

## 核心循环

```
农场产金 → 造兵/造建筑 → 占领据点(拓展可建区) → 升时代(T1→T2→T3)
    ↑                                              ↓
    └──── 兵营反还金币 ←── 推进战线 ←── 敌方骚扰波次施压
```

- **经济**：金币单资源。农场定时产金 + 兵营建造反还，无采矿农民（自动化经济，见 research/product/RTS_资源转化图分析.md）
- **军事**：兵营出兵（近战/远程/治疗三类基础 + T3 变体），快捷键 QWERASDF 直出
- **科技**：时代升级 T1→T3 解锁建筑/兵种；科技点作为暗线累积资源（造/杀/占获得）支撑解锁
- **目标**：主胜利条件为摧毁敌方基地；scripts/victory/ 下有 15 种条件可配置（护送/暗杀/守卫/生存等，战役关卡在用）

## 设计基调（做设计决策时的依据）

- **进攻优先**：核心体验是进攻敌方据点；骚扰频率要克制，避免把玩家逼成防守姿态
- **本阶段只做粗平衡**：经济/整体战力的粗平衡，数值小平衡等玩法定型后再做
- **操作做减法**：自动化经济、快捷键直出、QW 生产栏——朝"低操作门槛的 RTS"方向
- 玩法讨论方式见 standards/玩法设计讨论方法论.md
