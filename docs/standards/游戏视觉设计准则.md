# 游戏视觉设计准则

> 做新地图、新贴图、新单位、新特效、新 UI 之前，先过这份准则。
> 目的：把"这图太花了 / 单位看不见 / 风格违和"这类模糊感觉，变成可检查的规则。
> 依据：Valve Dota 2 角色美术指南、TF2/Overwatch 可读性分析、暴雪 Gameplay First 特效哲学、SC2 地图美术最佳实践（见文末来源）。
> 出图前另过《[动效锚点设计清单与生成图指导](动效锚点设计清单与生成图指导.md)》：本准则管能量与可读，那份管"为动效预留什么钩子"。

---

## 零、核心模型

游戏画面的一切视觉问题，都是同一个因果链：

```
玩家注意力是稀缺资源（RTS 几十单位 + 多线操作，认知负荷极高）
→ 画面每个元素都有隐含的"信息优先级"（玩家需要关注多少）
→ 每个元素的"视觉能量"必须与优先级匹配
→ 不匹配 = 看不见该看的（单位不显眼）/ 被不该看的抢戏（树太复杂、地面太花、特效爆炸）
```

**总规则：视觉能量的排序 = 信息优先级的排序。**

唯一与注意力无关的独立维度是"风格一致性"（第六节），它解决"格格不入"问题。

---

## 一、视觉能量（Visual Loudness）：抢眼程度的六个维度

评估任何资产"有多抢眼"，逐维打量：

| 维度 | 说明 | 强度排序 |
|------|------|----------|
| **明度对比** | 最强维度。人眼先读明度差再读颜色，"明度干活，色相邀功" | 对比越大越抢眼 |
| **饱和度** | 越鲜艳越抢眼 | 高 > 低 |
| **细节密度** | 高频细节（每片叶子、碎石纹理）= 视觉噪音 | 密 > 疏 |
| **运动** | 最强的注意力磁铁，动的天然被追踪 | 大幅 > 微动 > 静止 |
| **尺寸** | 同屏占比 | 大 > 小 |
| **色相稀有度** | 整片绿草地上的一个红点，比红本身更抢眼 | 稀有 > 常见 |

**用法**：新资产进游戏前问一句——它的六个维度加起来，比我方单位/敌人/预警圈更抢眼吗？如果是，砍。

---

## 二、注意力分层：三层能量配额

| 层级 | 内容 | 能量配额 | 设计目标 |
|------|------|----------|----------|
| **L1 玩法层** | 单位、血条、预警圈、投射物、资源变化 | 最高 | 瞬间可见 |
| **L2 状态层** | buff/debuff 标识、选中反馈、可交互点 | 中，且**短促** | 看一眼就懂，不持续干扰 |
| **L3 氛围层** | 地形贴图、树、装饰、天气 | **最低** | "被看见但不被注视" |

### 背景/装饰物规则（树、石头、废墟……）

- **大色块化**：轮廓可识别即可，砍高频细节。玩家永远不需要数叶子
- **明度压中调**：不能比单位亮，也不能黑成洞（黑窟窿同样吸睛）
- **饱和度系统性低于单位**：氛围可以有，前提是单位永远可读（SC2 官方原则）
- **微动或不动**：树摇曳幅度一旦接近单位动画就开始抢戏
- 装饰物的正确快感来源是"整体构图"，不是单件精美

### 地面（图底关系里的"底"）

- 地面是所有单位的背景板，它和单位的关系是系统性的：
  - **地面内部要平**：低频变化、大面积均匀，纹理频率低
  - **单位内部要有对比**：明暗结构清晰，轮廓找得到边
- "地面太亮"= 地面明度逼近/超过单位主体 → 单位被烧进背景
- "地面太花"= 地面高频纹理淹没单位轮廓
- 验收标准就一条：**去色后随便丢一个单位上去，浮得出来就过**

## 三、可读性：单位怎么被看见、被认出

两个独立子问题，分开检查。

### a) 看见 —— 图底分离（Figure-Ground）

- 单位与地面先比**明度差**，再比色相差。明度不够时调明度，别只调色相
- 系统性做法：地面取全局色板的"低饱和中调版本"，单位取"高对比版本"（见第七节色板）
- TF2 的极致做法：角色与场景共用一套受限色板，场景天然成为角色的对比背景——任何位置瞬间可读
- 反面教材 Overwatch：角色单看都漂亮，但明度层次缺失、色相各玩各的，群像糊成一团

### b) 认出 —— 剪影识别（Silhouette）

玩家阅读单位的顺序是固定的：

```
剪影 → 明度 → 色相 → 饱和度 → 细节
```

规则：

- 涂黑后仍能一眼认出**是哪个兵种、面朝哪边**。达不到就改轮廓，不是加细节
- 剪影传达功能：瘦削=敏捷脆皮，宽厚=坦克。体型即信息
- **RTS 特有约束**：固定俯视角 + 单位只有几十像素高，"细节"维度基本失效。识别全靠**剪影 + 主色块**。放大看很爽的细节，进游戏全是噪音
- 阵营色位置全单位统一（如同为肩膀/旗帜/盾面），且阵营色必须与环境色系拉开
- 单位内部要有**视觉休憩区**：大块平静色域 + 关键部位高对比（TF2 把最亮的颜色放在武器位引导视线，腿部压暗降级）。全身都是重点 = 没有重点

## 四、信息语法：每个视觉元素先回答"说什么话"

（特效的功能分类详见 [RTS特效分类与作用调研](../research/product/RTS特效分类与作用调研.md)：反馈/预警/标识/氛围四类。这里把同样的语法推广到所有视觉元素。）

### 做任何视觉元素前先问三句

1. 它传达什么信息？
2. 给谁看（我自己 / 所有玩家 / 观战者）？
3. 多紧急（需要 0.2 秒反应 / 看一眼就行 / 氛围而已）？

### 响度预算（Loudness Budget）

- **视觉强度随信息重要性递增**：预警 > 大招 > 普攻 > 移动反馈（暴雪 D4 原则："visually loud FX 留给强力技能，弱技能溶进背景"）
- 普攻特效就很大 → 大招没有提升空间，且屏幕永久超载
- 同层级元素同屏出现时也要有主次规则（两个大招同时放，谁响度高要预先定义）

### 颜色语义表（全游戏唯一，所有系统遵守）

| 颜色 | 语义 | 已有对应 |
|------|------|----------|
| 红 | 敌方 / 危险 / 预警 | 敌方血条、预警红圈 |
| 绿 | 我方选中 / 治疗 | 选中描边、治疗飘字 |
| 蓝 | 魔法 / 护盾 / 减速 | 蓝条、护盾环、冰蓝 tint |
| 紫 | 中毒 / 诅咒 | 中毒特效 |
| 黄/橙 | 增益 / 精英 / 注意 | 精英光环 |

- 同一颜色在两个系统里意思不同 = 玩家必然读错。新增视觉效果时先查此表
- 需要新语义时，优先复用已有颜色的"亮度/形状"变体，而不是引入新色相

### 可读性优先于物理正确

- 关键特效在任何地面/光照下都要可读：暗色地形上技能要自发光提亮，亮地形上要加深描边
- 特效与地面贴图同色系时（绿毒 vs 绿草地），用描边/形状/亮度强制区分

## 五、运动与安静：动态的能量管理

- 运动是最强的注意力磁铁 → **持续存在的东西必须安静，短促的东西才可以动**
- idle 单位不做持续抖动/呼吸（战场安静原则，已在《单位动态与状态视觉设计方案》执行）
- 持续型状态特效（buff 光环、燃烧）用低频呼吸，不用高频闪烁
- 冲量类反馈（受击、命中）动得猛但短：0.06–0.2 秒内结束
- 全屏都在动 = 全屏都不重要，玩家直接放弃追踪

## 六、风格一致性（Art Bible）：解决"格格不入"

"单位与世界观违和"通常是下面某一项被违反：

| 维度 | 内容 | 本项目基准 |
|------|------|-----------|
| 题材/时代 | 什么世界、什么技术水平 | 中世纪奇幻，冷兵器+有限魔法，无机械/电能 |
| 渲染风格 | 像素/卡通/写实，有无描边 | 2D 像素/卡通序列帧，无外描边（描边是选中态专用） |
| 比例体系 | 头身比、夸张度 | 统一 Q 版比例（新增单位须与现有四兵种并排校验） |
| 形状语言 | 尖角=危险、圆弧=友好，阵营内统一 | 人类阵营圆润规整；敌方可尖锐扭曲 |
| 调色板 | 全局色板，所有资产从中取色 | 见第七节 |
| 材质逻辑 | 该世界允许什么存在 | 木质/石质/皮甲/布料+魔法光效，无水晶科技感 |

### 混源素材的统一手段（本项目现实问题）

本作素材来自多个作者（Pipoya、CraftPix、itch.io 免费包），天然风格不一。外部素材落地前必须过一遍"统一化后处理"：

1. **饱和度校正**：向全局色板的饱和度区间靠
2. **明度校正**：向色板明度分区靠
3. **描边/发光规则统一**：同用途素材同处理
4. **并排校验**：新素材与 3–5 个现有同类素材并排截图，违和感立现
5. 校正做不到位的素材，宁可不用

## 七、全局色板（待建立，最高优先级的基础设施）

> 这张表是本准则的落地工具：建好后，"太亮/太花/违和"三个问题在源头被管住。
> 建议：截当前游戏画面取样现有颜色填入，作为 v1；之后所有新资产从色板取色。

| 分区 | 饱和度 | 明度 | 用途 | 色样（待填） |
|------|--------|------|------|------|
| 单位主色区 | 高 | 中亮 | 单位主体、识别色块 | |
| 阵营色区 | 最高 | 中亮 | 我方蓝 / 敌方红，位置统一 | |
| 状态色区 | 高 | 亮 | 红/绿/蓝/紫/黄（按颜色语义表） | |
| 地面色区 | 低 | 中调 | 地形贴图、路面 | |
| 植被装饰区 | 低-中 | 中调偏暗 | 树、草、石头 | |
| 建筑色区 | 中 | 中调 | 建筑、可交互物 | |
| 特效专用区 | 高-极高 | 亮-极亮 | 仅特效可用的最高能量色 | |

规则：

- **"特效专用区"的颜色只有特效可以用**。地面/装饰出现极高饱和色 = 必然抢戏
- 地面色区是单位色区的"降饱和降明度版本"，两区在色环上允许重叠色相，但能量参数拉开
- 色板 10–20 色以内。色板越大，风格越散

## 八、分资产类型验收清单

### 地图 / 地面贴图
- [ ] 去色截图后，单位浮得出来
- [ ] 纹理低频、大面积均匀，无高频噪点
- [ ] 明度在地面色区中调区间，无大面积亮斑/黑斑
- [ ] 饱和度在地面色区内
- [ ] 不同地块拼接处明度连续（不为拼接好看而拉对比）

### 装饰物（树 / 石头 / 废墟）
- [ ] 大色块，无高频细节
- [ ] 比单位暗或更灰，不与单位争能量
- [ ] 动画幅度远小于单位动画，或静止
- [ ] 与 3–5 个现有装饰并排截图不违和

### 单位
- [ ] 涂黑剪影可识别兵种与朝向
- [ ] 游戏实际尺寸（缩小后）可识别，而非只在编辑器里放大好看
- [ ] 与地面去色对比明显
- [ ] 阵营色位置与现有单位一致
- [ ] 体内有视觉休憩区，关键部位（武器）对比最高
- [ ] 与现有单位群并排截图，剪影互不混淆
- [ ] 符合 Art Bible 六维表

### 特效
- [ ] 能说出信息语义（反馈/预警/标识/氛围哪一类）
- [ ] 响度与技能威力匹配（普攻收敛、大招放开）
- [ ] 颜色符合语义表
- [ ] 在最亮和最暗的地面上都可读
- [ ] 时长与信息紧急度匹配（预警够人反应，反馈短促）
- [ ] 多个同屏叠加后截图检查不糊成一团

### UI
- [ ] 贴边布置，中心留给战场
- [ ] 数字 > 图标 > 装饰的能量排序
- [ ] 交互色语义与游戏内一致（红=危险/不可用，绿=可用）
- [ ] 面板背景比战场任何区域都"安静"（低对比压底），信息元素在其上高对比

## 九、自检测试方法（比准则更值钱）

| 测试 | 做法 | 检验什么 |
|------|------|----------|
| **灰度测试** | 战斗截图去色（可加模糊） | 图底关系。不通过调明度，别调色相 |
| **实际尺寸测试** | 单位缩到游戏内真实大小 | 剪影与主色块可识别性 |
| **游戏相机测试** | 新资产放进真实场景截图评估，永不在素材库里单独看 | 一切。单独看永远好看 |
| **群像测试** | 20+ 单位混战 + 特效全开截图 | 混合可读性（单测都过、混战糊团是常见翻车点） |
| **0.5 秒测试** | 给没玩过的人看截图半秒，问"什么在打你？你的兵在哪？" | 层级是否真正成立 |
| **响度审计** | 同屏动态元素按抢眼程度排序 | 排序是否等于信息重要性排序 |
