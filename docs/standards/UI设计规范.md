> **何时查它**：改任何 UI / 新增任何 Control / 评审 UI 提案之前。布局尺寸查第 2 章、token 查第 3 章、交互与动效数值查第 4-5 章、组件查第 6 章。
> **地位**：T4 A.2 产出。管「布局 / 尺寸 / 结构 / 交互」；颜色可读性归 [游戏视觉设计准则](游戏视觉设计准则.md)；工程事实（CanvasLayer 分层/已知 OOB）归 [ui_specs](../reference/ui_specs.md)；AI 改码操作规程归 CLAUDE.md。
> **依据**：[游戏UI规范_业界标准与交互反馈数值调研](../research/product/游戏UI规范_业界标准与交互反馈数值调研.md)（业界六层结构 + 18 项数值包 + 第 3 章专业审查）。拍板过程见 [A2_UI规范_章节问答草稿区](../plans/A2_UI规范_章节问答草稿区.md)（2026-08-15，7 章逐项问答）。
> **维护**：数值随实施演进；修改走文档修订，不鼓励单点 override。

## 1. 玩家假设与核心原则

### 玩家状态假设（本规范的推导起点）

> 玩家在单局中默认处于**枕戈待旦**状态：随时准备召唤部队投入战斗——按编队 1、A 地板，或按 Y 释放技能，这些操作**任何时刻都应该可以无摩擦地完成**。运营（建造/升本）是次优先级活动，为战斗服务。

1.1 的五条方向型原则全部由此推导。

### 1.1 方向型原则（信息架构层——往哪设计）

| # | 原则 | 内容 |
|---|---|---|
| A1 | **状态可读性** | 玩家任意时刻扫一眼屏幕，能回答三问：*我在赢吗？下一个威胁在哪？经济健康吗？*（资源栏/波次倒计时/小地图常驻存在的理由） |
| A2 | **信息顺序 = 战斗优先** | 信息呈现按 **交战情况 → 敌方关键单位状态（boss 血量/施法/集火目标）→ 资源运营** 排序。冲突时高优先级允许遮挡低优先级，反之禁止（映射表见 2.3） |
| A3 | **Red Routes 零层级可达** | 核心战斗操作——编队选择、A 地板、指挥官技能热键——任何时刻直接可按：不进菜单、不被低优先级弹窗抢占、不依赖先点选别处。运营操作允许进 tab 菜单 |
| A4 | **菜单分块** | 单层菜单选项 **≤6**；更多时先按职能分类（如 肉盾/输出/治疗，**≤4 类**）类内再选。禁止 20 个选项平铺一层 |
| A5 | **ESC 逐层取消** | 任何界面状态有统一后退路径且行为可预测：按键页 → 设置 → 暂停 → 游戏逐层退（收编 `handle_pause_esc` 现有行为） |

### 1.2 戒律型原则（不许违反什么）

| # | 戒律 | 内容 |
|---|---|---|
| P1 | **信息区 ≤2** | 顶 + 底 UI 合计 ≤30% 垂直空间（SC2/Dota2 实测基准；现状仅底部一区 ✅） |
| P2 | **垂直成本 2:1** | 新 UI 优先占水平（侧栏/悬浮/全屏切换），不再吃垂直。例外：底部命令栏是 RTS 玩家约定俗成的注意力区，独占垂直值得 |
| P3 | **任务必需信息常驻** | 建造消耗等任务必需信息不许藏进 tooltip，必须常驻控件本体 |
| P4 | **高频操作零等待** | 建造连点/tab 切换/框选等高频操作无动画或 ≤50ms（详见 5.3） |
| P5 | **错误提示必须带解法** | "金币不足"是半句，"金币不足（需要 150）"才是完整反馈 |
| P6 | **同一控件同一行为** | 全站一致。违反实例：tooltip 曾有两套延迟（600/800ms）——规范的价值大半在这条 |

## 2. 布局与屏幕分区

### 2.1 屏幕基准

- **表述基准 1920×1080**；代码逻辑坐标系 1280×720（canvas_items / expand）不动，1080p 全屏下所有值自动 ×1.5 投影
- 本文档所有尺寸两列标注：**逻辑 px / 1080p 物理 px**
- 战场可视区：上 500 / 750（1080p 下底部栏实际 330 物理 px）

### 2.2 底部命令栏（唯一垂直占用者）

**整体** [0, 500, 1280, 220]，三段横排 HBox separation=4：

| 段 | 名义比例 | 逻辑宽 / 物理宽 | 内容 |
|---|---|---|---|
| QW 建造栏 | 30% | 384 / 576 | tab（单位/建筑/据点）+ 每 tab 横排按钮。⚠️ #12 待定：是否改 4×3 网格 |
| 详情面板 | 40% | 512 / 768 | 左 stats / 右升级+造兵（ScrollContainer） |
| 小地图 | 20% | 256 / 384 | 186×186 固定，RTS 最高频注视点右下锚定 |
| 剩余 ~10% | — | — | 呼吸空间，不明确分配 |

- 内部可用高度 220 − padding 16 = **~204 / 306**，新增节点必须先算这笔账
- QW 溢出修复方向 = A4 职能分组，与 #12 待定项一起处理

### 2.3 信息优先级 → 屏幕区域映射（A2 落地）

| 优先级 | 信息 | 区域 | 形式 | 遮挡规则 |
|---|---|---|---|---|
| **L1 战况** | 交战爆发、boss 施法、**boss/精英血条** | 战场本体（世界空间） | 特效 + 飘字 + 头顶血条 | 可遮 L2/L3；可短暂越入 UI 区（飘字层 15 已实践） |
| **L2 关键状态** | 波次倒计时、编队血量 | 小地图区 + 顶部 objectives | 常驻 HUD | 不遮 L1；可遮 L3 |
| **L3 运营** | 资源、建造队列、升级 | 资源栏（左上）+ 底部栏 | 常驻 HUD | 不遮任何 |

- boss/精英状态 = **L1 头顶血条**（世界空间，2-2 拍板）；施法提示复用已有 telegraph 世界内特效；不做顶部横幅
- 弹窗模态分级：停转模态（暂停/结算，layer 100）游戏停转时才允许；**运行中模态**（T3 选一，layer 95）不得阻断 L1 信息获取（不暂停游戏、ESC 链明确、Red Routes 热键失效需标注）

### 2.4 顶部与浮窗

- 资源栏（左上 [10,10]）、objectives（右上）、指挥官技能（顶部居中）、倍速（左下）——坐标细节见 [ui_specs](../reference/ui_specs.md)
- 新增浮窗默认落位顺序：右上 → 左下 → 全屏切换（P2 水平优先）

### 2.5 新 UI 提案三问（审计规则）

1. 占垂直吗（P2）？ 2. 遮了谁（按 2.3 表）？ 3. 抢了小地图注意力吗（波次红点等战况信号不许被常驻元素稀释）？

## 3. 视觉基础

### 3.1 字号阶梯

M3 尾部四档，行高按 4px 节奏（参照 Material M2 4dp baseline grid；12px 档中文行高提到 20）：

| 档 | 逻辑 / 物理 | 行高 | 用途 |
|---|---|---|---|
| display | 22 / 33 | 28 | 资源数字、面板标题 |
| body | 16 / 24 | 24 | 按钮主文案、详情正文 |
| caption | 14 / 21 | 20 | 造价、辅助说明、tooltip |
| micro | 12 / 18 | 20 | 计数徽标、FPS、热键角标——**限非任务关键信息** |

- 禁止中间值（15/17/19 等）
- micro 档 12px@720 逻辑 = 18px@1080 恰好压线 Xbox XAG PC 最低值**零余量**——知悉项：不再新增 <12px 文字；移植主机需整体重排（见第 7 章）
- 关键任务信息（资源数/倒计时）最低 caption 档

### 3.2 字体

- **内嵌思源黑体**（= Noto Sans CJK 同字型双品牌，OFL 免费商用），≤3 字重（自带 7 真字重选 3）
- 配项目 theme default font，**禁用系统回退**（Godot 4 运行时默认 Open Sans SemiBold 无中文字形，中文会回退系统字体跨平台不一致）
- **数字等宽**：资源数字 Label 统一挂 tnum（`FontVariation.opentype_features = {"tnum": 1}`）防跳动；思源黑体 tnum 未实测，抖动则数字 fallback Noto Sans Mono
- 禁止 add_theme_font_override 散落指定字体，换字体单点替换

### 3.3 图标

- **新图标源图一律 128×128**（显示 72×72，1.78 倍超采样）；现有 76 系列沿用，逐步替换
- 透明底、禁自带容器/白底/圆角（容器与边框由 UI 层绘制，同 SC2 分层）

### 3.4 间距 token

| token | 值（逻辑 px） | 用途 |
|---|---|---|
| space-1 | 4 | 图标与文字间距、紧凑行距 |
| space-2 | 8 | 按钮内 padding、组件间距默认 |
| space-3 | 12 | 面板内边距 |
| space-4 | 16 | 面板间/分区级间距 |
| space-5 | 24 | 布局分区 |
| space-6 | 32 | 布局分区 |
| space-7 | 48 | 大分区 |
| space-8 | 64 | 大分区 |

全部 4 的倍数、8 优先；禁止 5/7/9/11 等奇数值。

### 3.5 功能色（三层 token）

```
A.3 全局色板（primitive，美术资产同源）
    ↓ 只经 semantic token 引用
UI semantic token（深底专用值）
    ↓
组件 token / 组件直接引用 semantic
```

- 四个语义 token：`error` / `success` / `warning` / `info`，各**唯一值**（收编现有三档红 0.3/0.4/0.75、两档绿、一档黄）
- **禁止 UI 组件直接写美术色值**；纯深底项目直接为深底选色，不做亮暗换肤
- 验收：XAG 102（= WCAG）**4.5:1 正文 / 3:1 图标与大字**
- 辅助语义：`locked`（时代锁定紫灰，与 disabled 灰拉开明度差）

## 4. 交互规范

### 4.1 交互五态

> **降级规则**：状态反馈用**明暗/缩放/透明度**表达，不换色相——hover 变亮、按下变暗、禁用变透明。Tiny Swords 有限色板下不为任何状态画新贴图；色相只留给语义色（error/locked）。

| 态 | 数值 | 时长 |
|---|---|---|
| enabled | 基准 1.0 | — |
| hover | scale 1.12 + 变亮 12% | 0.1s ease-out |
| pressed | scale 0.90 + 变暗 20% | 0.1s ease-out |
| disabled（真） | modulate 0.4，不可点、hover 无反馈 | — |
| 压暗可点（假禁用） | 视觉压暗但保持可点，点击触发报错 | — |
| 选中/当前 tab | 描边或角标高亮（持续态不用缩放） | 0.1s 过渡 |

**禁用双轨制**（4-1 拍板）：

- **真禁用**（满级 MAX / 单次已购 / 队列满）= 0.4 不可点无反馈
- **假禁用**（缺钱 / 时代锁）= 压暗**可点击**，点击触发报错飘字——SC2 式「点它问原因」，正式化现有散落行为

### 4.2 Tooltip

| 项 | 值 |
|---|---|
| 出现延迟 | **300ms**（全站唯一值） |
| 消失延迟 | 200ms；鼠标移入 tooltip 本体不消失 |
| 出现动画 | 100ms 淡入（motion-fast） |
| 位置 | 锚定按钮上方，不遮挡按钮本体与相邻按钮 |
| 内容结构 | **名称 → 消耗 → 热键 → 描述**（SC2 四段式）；消耗同时常驻按钮（P3） |
| 红线 | 任何热键操作的有效性不许依赖 tooltip 讲清（P3 延伸） |

### 4.3 报错与反馈（三通道）

| 通道 | 规范 |
|---|---|
| 文字 | 世界飘字，文案公式 **[缺什么] + [需要多少] +（可选）[去哪弄]** |
| 音效 | 场景→类型映射见 4.5 需求清单（C.2 实施） |
| 视觉强化 | 点击不足按钮时**消耗数字闪红 200ms** |

- **无效放置**：保留绿/红 ghost，补一行原因（"离基地太远"等）
- **不新建 toast 系统**（波次预警已有常驻倒计时 + 世界 marker + 小地图红点）；未来若做：普通 3s / 重要 4s / 同屏上限 3 条
- 飘字时长（弹出 0.3s / 漂浮 2.0s / 淡出 1.2s）保留，属信息载体类（见 5.4）

### 4.4 微文案

- 数字用阿拉伯不写汉字；>999 显示 1.2k
- 全部文案走 translations.csv，**禁止硬编码中文**
- 术语唯一：同一实体全域一个名字（"据点"不混"前哨"）

### 4.5 音效需求清单（交付 C.2）

| 场景 | 类型 | 优先级 |
|---|---|---|
| 报错（金币不足/队列满/时代锁/无效放置） | 短促错误音，全部报错共用一种 | P0 |
| 波次预警（warning_time 触发） | 警报音，与错误音区分 | P0 |
| 按钮点击 | 轻点击音（可配静音） | P1 |
| 建造完成 / 升级完成 | 成功短音 | P1 |
| 时代解锁 | 上扬音 | P2 |
| 指挥官技能施放/就绪 | 技能音/就绪提示 | P2 |

## 5. 动效规范

### 5.1 三档 token

| token | 时长 | 用途 |
|---|---|---|
| motion-fast | 100ms | 按钮态切换、tooltip 淡入、闪红、选中过渡 |
| motion-medium | 250ms | 面板开关、建造栏 tab 切换（若做） |
| motion-slow | 400ms | 全屏遮罩、结算页淡入 |

**硬上限：任何反馈类动效 ≤500ms。**

### 5.2 缓动规则

| 场景 | 缓动 |
|---|---|
| 进入（弹出/淡入/放大） | ease-out |
| 退出（消失/淡出/收起） | ease-in |
| 屏内移动（tooltip 跟随/面板滑动） | ease-in-out |

### 5.3 高频操作零等待（P4 落地，RTS 特权）

**无动画或 ≤50ms 白名单**：建造连点、tab 切换、框选、编队切换、小地图点击、镜头跳转。
M3 的 250ms 面板动画**不得**照搬到高频路径——这是 RTS 与 app UI 的根本差异。

### 5.4 事件动效与豁免条款

> **判定口诀**：动效是**反馈**（告诉玩家发生了什么）→ 受 token 与 500ms 封顶管；动效是**信息载体**（本身就是内容）→ 时长按"够玩家读完"定，豁免封顶。

| 事件 | 规范 |
|---|---|
| 时代解锁按钮闪 | 0.5s → **0.4s**（压进 slow 档） |
| 飘字 / 血条动画 | **信息载体类豁免**（3.2s 总时长保留） |
| 单位出生/升级完成 | 一次性 200-400ms 允许 |
| 波次 marker 脉冲 | 持续型低频呼吸类（归视觉准则第五节管） |

飘字系统未来重新设计（已记 gap），届时豁免条款再审。

## 6. 组件规范

按 Toptal 四分类收编 **Non-diegetic（HUD）+ Spatial（世界空间）** 两类；Diegetic 归视觉准则、Meta 归战斗表现。**菜单流界面（lobby/存档/房间/主菜单）不做卡片**，只遵守 1/3/4/5 章通用规范。

### 6.1 命令按钮（核心组件，全部数值装订表）

| 维度 | 规范值 |
|---|---|
| 尺寸 | wrapper 72×72 / ButtonBG 90×94 / 图标源 128（旧 76 沿用） |
| 结构 | wrapper(Control) → ButtonBG(NinePatch) + 图标 + Label + Button + CostLabel（装饰组白名单模式） |
| 五态 | 见 4.1（含禁用双轨制） |
| 动效 | 态切换 0.1s ease-out；连点无动画 |
| 文字 | 图标下 Label body 16 / 造价 caption 14 **挂 tnum** / 热键角标 micro 12 |
| Tooltip | 300ms 弹出，锚按钮上方，四段式内容 |
| 语义色 | 造价不足 = error token / 时代锁 = locked token（不直写色值） |

### 6.2 飘字（Spatial 模板）

- 定位：信息载体类（5.4 豁免适用者）
- 结构：Label 24px + 阴影 0.7，CanvasLayer 15（盖 UI 不盖暂停）
- 节奏：弹出 0.3s BACK-OUT → 漂浮 2.0s（-80px）→ 淡出 1.2s
- 颜色：semantic token，禁止随手 Color(...)
- ⚠️ 已列重设计清单，本卡为过渡规范

### 6.3 弹窗模板（暂停/T3 选一/结算通用）

| 维度 | 规范值 |
|---|---|
| 层级 | 停转模态 CanvasLayer 100 / 运行中模态 95 |
| 遮罩 | 黑 50%，入场 0.4s（motion-slow） |
| 面板 | 居中，入场 0.25s（motion-medium）ease-out |
| 模态规则 | 运行中模态不得阻断 L1（不暂停/ESC 链明确/Red Routes 热键失效标注） |
| 按钮 | 引用 6.1 |

### 6.4 组件卡片目录（每组件一卡，实施时逐卡补齐）

资源栏 / objectives 面板 / 小地图 / 建造队列指示 / 冷却遮罩（顺时针从 12 点填充 + 秒数，就绪可闪白 100ms）/ 选中圈 / **头顶血条（新组件，随实施建卡）** / 据点状态面板 / 升级进度圈 / intro 提示 / 大战术面板。

## 7. 无障碍与本地化（最小版）

- **色盲冗余：不做**（拍板 2026-08-15）。飘字自带文字本身即语义冗余，实际风险低；色盲滤镜等玩家反馈后再议
- **字号下限**：12px 逻辑（=18px@1080p）为全项目绝对下限且仅限非任务关键信息，压线 XAG PC 值零余量；移植主机需整体重排
- **本地化宽度**：全部 UI 文案走 translations.csv 禁硬编码中文；含文案按钮宽度预留 **+30%** 余量（或容器自适应）
