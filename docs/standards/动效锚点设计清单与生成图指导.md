# 动效锚点设计清单与生成图指导

> **用途**：做任何新视觉资产（建筑/单位/装饰/投射物/UI）**出图之前**，过这份清单。它回答一个问题：这张图要为"以后能动起来"预留什么。
>
> **与《[游戏视觉设计准则](游戏视觉设计准则.md)》的分工**：准则管"能量与可读"（多抢眼、能不能被看见）；本清单管"钩子与状态"（留什么结构、什么状态怎么表达）。两份都要过，不冲突。
>
> **依据**：[动效友好美术设计_跨游戏调研](../research/product/动效友好美术设计_跨游戏调研.md)（术语/案例/规律）。

---

## 一、核心原则：AI 画"钩子"，不画"动画"

1. **静态图只负责"有结构可挂"**：烟囱、旗杆、窗户、飘带、魔法壶是钩子；烟、旗、灯光、粒子是引擎特效。**出图时一律生成"中性暗态"**（烟囱口无烟、窗户不发光、灯笼未点燃），动效在引擎里挂。
2. **不要让 AI 画动态内容**（烟雾/光晕/拖尾/火焰）：① AI 多帧一致性差，没法做序列帧；② 画进图的烟关不掉，状态切换（亮窗↔暗窗）就废了；③ 光效该由引擎 additive 层做，可调可控（调研规律 1、5）。
3. **例外**——两种"帧级便宜货"可以要 AI 出：**两态图**（开花/不开花各一张，构图一致做互换）和 **2-3 帧微动**（先出 1 帧定稿，2/3 帧手修，不指望 AI 直接出序列）。

---

## 二、设计流程四步（出图前过一遍）

```
① 想状态 → 这个资产有哪些状态？（idle / 工作中 / 受击 / 充能 / 升级 / 已用尽……）
② 选钩子 → 每个状态至少一个可视差异点，从下面第三节大清单里选
③ 定挂法 → 每个差异点选挂接方式（成本从低到高）：
            引擎开关（visible/mask 开关） < 引擎提亮（modulate/additive）
            < 两帧互换 < 程序摆动/旋转 < 子节点动画（小人/环绕物） < 换整张贴图
④ 写进提示词 → 套第四节模板，锚点结构写进结构要求区，负面约束带上
```

出图完成后：**回填锚点坐标表**（第四节末尾），配置组件时直接抄。

## 三、大清单：可设计的动效锚点与细节

职责标注：**氛围**=让画面活、**状态**=传达游戏信息、**双**=两者兼得（优先做，调研规律 2）。

## 四、AI 生成图指导（文生图通用）

### 4.1 提示词模板

三个模板的结构固定为四段：**类型与风格锚 → 结构要求（钩子清单）→ 风格参考 → 负面约束**。结构要求一条一行，逐条对应大清单。

**模板 A：建筑**

```
像素风中世纪奇幻建筑【建筑名】，2.5D 等距视角，粗黑描边，Q版比例，单张完整贴图。
结构要求（动效锚点，必须清晰可辨）：
- 屋顶带一座砖砌烟囱，烟囱口朝上，无烟
- 正面两扇矩形窗，暗色玻璃，不发光
- 拱形木门上方有灯笼挂钩，挂钩为空
- 屋顶塔尖带旗杆，无旗
- 门前留一小块平整空地
风格参考：与附件建筑贴图同一套风格（附 Tiny Swords 参考图）
负面：不要烟雾、不要发光窗户、不要火焰、不要飘动的旗帜、不要已点燃的灯笼
```

**模板 B：角色**

```
像素风中世纪奇幻【兵种名】，2.5D 侧视可四向，粗黑描边，Q版头身比，与附件单位贴图同套风格。
结构要求（动效锚点，必须清晰可辨）：
- 腰间挂一只魔法壶（或：灯笼/药瓶），壶口朝上，壶体暗色无光
- 背后垂坠披风，单色无图案，下摆自然下垂
- 武器刃部有简单刻纹，暗态不发光
负面：不要粒子、不要光晕、不要拖尾、不要烟雾、壶不要发光
```

**模板 C：地形装饰（两态）**

```
像素风【装饰名：花丛】，2.5D 微俯视，粗黑描边，与附件贴图同套风格。
分两次生成，构图、视角、茎叶位置完全一致：
第一张【开花态】：花朵完全绽放，颜色清晰但不过饱和
第二张【未开花态】：只有花苞与叶子，花苞位置与开花态花朵位置一致
负面：不要发光、不要飘落的花瓣、不要露珠高光
```

**两态生成要点**：同一次对话里连续生成（保持风格种子），或以第一张为参考图 img2img 改第二态；两张叠图检查偏移，偏移超过 2px 手动对齐。

### 4.2 挑图标准：钩子齐全度

AI 一次出多张候选，按下面逐项打勾，缺钩子的图直接淘汰（画面再好看也不选——钩子是本次出图的目的）：

```
[ ] 清单要求的锚点结构全部可见且可辨（烟囱/窗/旗杆/携带物…）
[ ] 锚点为中性暗态（无烟/无光/无火）
[ ] 涂黑剪影仍可认出资产类型（准则第三节）
[ ] 与 3-5 个现有同类资产并排不违和（准则第六节）
[ ] 实际游戏尺寸下可辨（准则第九节：实际尺寸测试）
```

### 4.3 出图后处理与登记

1. **切层**：需要独立摆动的件（旗帜、灯笼、烟囱帽）从主图切出为 overlay 小图，主图对应位置补底色。
2. **回填锚点坐标表**（资产表新增列，或独立 sheet）：

```
资产名        | 锚点      | 坐标(贴图像素) | 挂接方式      | 状态语义
blue_barracks | 烟囱口    | (52, 8)       | 粒子挂点     | 在生产
blue_barracks | 左窗      | (34, 41)      | 引擎提亮     | 工作中/夜间
blue_barracks | 门前空地  | (64, 92)      | 子节点小人   | 训练中
```

3. **两态资产归档**：`xxx_on.png` / `xxx_off.png` 成对存放，命名后缀统一，引擎里按状态切帧。

## 五、分资产验收清单（出图完成时勾）

**建筑**
- [ ] 至少 1 个双职责锚点（烟囱/窗户/内容物之一）
- [ ] 锚点坐标已登记
- [ ] 无画死的动态内容（烟/光/火）

**角色**
- [ ] 至少 1 个次级运动件（披风/飘带/头发/尾巴之一）
- [ ] 法系/带技能单位有特效携带物，且为暗态
- [ ] 剪影测试通过，携带物不破坏兵种识别

**地形装饰**
- [ ] 有状态语义的装饰已出两态图并对齐
- [ ] 摆动类幅度设计 ≤ 单位动画的一半

**投射物/技能**
- [ ] 三码（形状+色相+拖尾）与现有弹体无冲突
- [ ] 色相符合颜色语义表

**UI**
- [ ] 动效不遮挡信息，能量低于 L1/L2 层（准则第二节）
