# 机制好坏判据

> **何时查它**：评审新机制提案时逐条过、决定砍不砍某功能时、设计新机制后自查。
> **本文的边界**：每条判据都来自本项目真实决策/踩坑（实证），不是通用设计格言。通用讨论工具（跨游戏反模式、甜区、因果可见性、失败归因）见 [玩法设计讨论方法论](玩法设计讨论方法论.md)，本文只引用不重复。

## 二、坏机制判据详解

### 坏1：强制计时锁死已达成目标的玩家

- **判据**：玩家已经达成机制设计的目标，却被计时器/流程拦住，不能提前结束。
- **案例**：VictorySurviveTimer——胜利条件是"存活 N 分钟"，玩家提前把敌人打穿了仍要干等到计时结束。
- **为什么坏**：玩家的成功被系统否认。前 N 分钟积累的优势无法兑现，体验从"我赢了"变成"系统还没让我赢"。
- **补救方向**：目标达成即胜利（事件驱动），计时只做失败线（撑不到才输），不做胜利线。
- **边界**：无。"提前通关被拦"没有任何合理场景。

### 坏2：诱导玩家偏离核心姿态

- **判据**：机制把玩家从游戏的核心体验姿态逼向另一种姿态（本作：进攻 → 防守）。
- **案例**：敌方骚扰频率过高时，玩家最优解变成在家修塔蹲守，核心的"进攻敌方据点"没人做了。
- **为什么坏**：游戏的核心爽点被机制惩罚。玩家"正确地玩"却得到不快乐的体验，长期会归因为本作不好玩。
- **补救方向**：控制骚扰频率的上限（克制）；骚扰目标是资源边缘而非主基地；让进攻本身成为最好的防御（推掉据点 = 减少骚扰源）。
- **边界**：防守段作为节奏调剂可以短暂存在（如波次间隙的防守反击 timing），但不能成为主要姿态。

### 坏3：PVE 下不产生决策的互动

- **判据**：一个东西与玩家互动的方式里没有任何选择空间（打或不打、绕或直走、先或后都一样），只是流程噪声。
- **案例**：中立物调研（[PVE视角调研](../research/product/中立物设计_PVE视角调研.md)）确立的两问过滤法——"是否产生博弈？是否解决玩家不出基地的问题？"两问都否的中立物，纯摆设。
- **为什么坏**：占玩家注意力但不给回报。玩家初期会探索它，发现无意义后转为视觉噪声，还会稀释真正有意义的互动的信噪比。
- **补救方向**：砍掉，或给它一个决策维度（可破坏获取资源 / 驻扎 / 挡路形成地形博弈）。
- **边界**：纯视觉装饰（树/草）不算坏机制——它们不索求玩家注意力，定位是美观。索求了注意力又不给决策的才是。

### 坏4：规则玩家猜不到（隐性前置）

- **判据**：玩家无法从 UI 和常识推断出规则的存在，只能靠撞墙或查文档。
- **案例**：占领据点后想圈里造农场被拒绝——隐性前置"必须先造祭坛"，圈不变色、无提示、无引导。
- **为什么坏**：玩家体验到的是"被系统随机拒绝"。学习成本大于机制收益时，玩家不会觉得"这游戏有深度"，只会觉得"这游戏有 bug"。
- **补救方向**：可视化（圈颜色区分阶段）、前置提示（占领时弹"下一步可造祭坛解锁拓展区"）、或干脆砍前置（占领即可造）。
- **边界**：有些深度规则允许隐性（进阶技巧、组合技），判断标准是"撞墙是否在核心路径上"。核心路径（建造/出兵/升本）的规则必须显性。

### 坏5：纯数值墙制造难度

- **判据**：难度提升只靠敌人数值变大变多，不引入新机制或新组合。
- **案例**：T4 波次设计（[总览](../plans/T4阶段设计_00_总览.md) B.1）明确规避——每波 difficulty 提升须来自单位 composition 变化，不是单纯数值堆高。
- **为什么坏**：玩家的应对方式不变（还是那套操作），只是容错率变低。前两波好玩，后面每一波都是同一波的重播，玩家疲劳。
- **补救方向**：每波引入新构成（新兵种/新比例/新方向）、新约束（时限/保护目标）或新地形要素，让玩家每波都要重新决策。
- **边界**：波次内部的小幅数值成长（+10% HP）是必要的节奏粘合剂，问题只出在"只靠数值"。

### 坏6：高潮押在一次性大招上

- **判据**：游戏体验的峰值完全依赖一个一次性事件（终极兵海 / 决战 BOSS / 梭哈时刻），事件前后都是平淡。
- **案例**：T4 决策 D4——不做梭哈时刻，节奏自然结束（[总览](../plans/T4阶段设计_00_总览.md)）。
- **为什么坏**：虎头蛇尾。一次性大招的刺激无法支撑其前后的平淡期；且大招设计稍弱，整个游戏的记忆点就崩了——风险集中在单一事件上。
- **补救方向**：把峰值摊到多个小高潮（timing 节点、多波构成变化、关键科技解锁），靠节奏曲线本身制造张力。
- **边界**：Boss 战 / 终局仪式感场景例外——一次性大事件作为**奖励**（玩家打穿进程的加冕）而非**考题**（决定成败的门槛）时成立。

### 坏7：UI 所见非所得

- **判据**：UI 呈现的状态与实际行为不一致——按钮看起来能点实际不能、tab 看起来是 A 实际按了进 B。
- **案例**：Tab 建造栏系列（TODO 操作优化条目）：选中建筑后底部栏停留"造建筑"tab，按 Tab 却切到"造兵"tab；科技已解锁但钱不够时按钮看似可点。
- **为什么坏**：直接破坏操作信任。玩家每次操作前都要怀疑 UI，认知成本全部花在"验证界面"而不是"做决策"上。
- **补救方向**：状态与呈现强绑定（选中建筑 → 自动切对应 tab）；不可用必须显性表达（灰显 + 原因飘字），点击拦截要立即反馈原因。
- **边界**：无。这是红线级问题，任何"看起来能但实际不能"都是 bug 级体验。

### 坏8：错过时机窗口的机制硬加

- **判据**：某机制在架构上要求 day 1 内建（网络同步、存档结构、核心数据模型），项目已过该时点仍试图补加。
- **案例**：多人模式判「永不」——[T4 总览](../plans/T4阶段设计_00_总览.md) 砍除表：Empires of Undergrowth 教训，多人架构必须 day 1 内建，事后加等于重写。
- **为什么坏**：不是机制本身坏，是成本结构坏。硬加的代价是全局重构，会拖垮所有并行开发的内容。
- **补救方向**：承认窗口已关，正式写进砍除表（带原因），避免每次讨论重复心动。想做就开新项目，day 1 带上它。
- **边界**：多数机制没有 day 1 约束（单位、建筑、关卡随时能加）。判据只适用于架构耦合型机制。

## 三、好机制判据详解

### 好1：玩家自选时机

- **判据**：节奏断点（升本/解锁/进阶）由玩家的行动触发，不由系统时间强制。
- **案例**：T1/T2 沉淀（[T3阶段设计_终局与扩展](../archived/T3阶段设计_终局与扩展.md) 第三章）：事件驱动定义阶段 + 玩家自选升级时机，而非固定分钟数切换。
- **为什么好**：不同节奏的玩家（贪经济/激进爆兵）都能按自己的曲线走，同一系统支持多种玩法；系统时间强制会把某一种节奏定为"正确答案"。
- **代价**：平衡更难（要验证各时机都可行，见好2）；引导要另做（没有固定时间轴可依附）。
- **边界**：敌方波次这类"对抗节奏"仍需脚本时间轴（D2 决策）——自选时机适用于玩家侧成长，不适用于敌人侧压力。

### 好2：支持多种战略路径

- **判据**：主流可行路径 ≥ 3 条，没有一条碾压其余，也没有一条全程被压。
- **案例**：[T3阶段设计_A模块经济推演](../archived/T3阶段设计_A模块经济推演.md)——6 种战略路径（不升本/远近搭配/T3 强化/纯近战…）推演终态，验证多条路径成立。
- **为什么好**：选择的含义是"都有代价、都可活"。路径单解后游戏变成执行流程表，重玩价值归零。
- **代价**：每条路径都要维护平衡；测试成本翻倍；数值膨胀风险（为救弱路径不断加码）。
- **边界**：demo/早期版本允许主推 1-2 条路径先跑通，但要明确标注"其余路径未验证"，正式版前补推演。

### 好3：可取消、可退款、可逆

- **判据**：玩家的重大投入（建建筑/升本/选升级）提供安全的退出通道：可取消、全额或高比例退款、不锁死。
- **案例**：升级中可取消全额退款（T1/T2 沉淀）；建筑拆除返还（building.gd 反还逻辑）。
- **为什么好**：鼓励尝试。玩家知道"选错能回头"才敢试新策略，系统深度才被探索；不可逆的惩罚让玩家只走已验证的安全路线。
- **代价**：可能被滥用（试探性放置骗信息）；退款比例要平衡防刷。
- **边界**：战斗中的战术决策（走位/选目标）必须不可逆，可逆的战场等于无战场。本判据只适用于建造/科技/成长类投入。

### 好4：增益必带代价

- **判据**：任何新增强度（AoE/硬控/高机动）必须同时引入等值代价，净增益接近零。
- **案例**：[单位设计公式化指南](单位设计公式化指南.md) 平衡税则——加 AoE → 单发伤害 -30~50%；加硬控 → 伤害 -40%；加高机动 → 血量 -25~40%。
- **为什么好**：数值不通胀。每个单位强在一点弱在一点，才有"用谁"的决策；无代价的增益会让旧内容集体过期，设计债滚雪球。
- **代价**：设计变难（每加东西都要找税基）；税则过严会让新内容平庸无亮点，需要偶尔发"超模但有趣"的例外并明确标注。
- **边界**：PVE 向的爽点单位（玩家侧对 AI）可以阶段性超模——AI 是数值的对手不是博弈的对手，乐趣优先于对称平衡。
